# 오븐 (Oven)

> 오븐은 뜨거운 공기 상자가 아니다. 복사·대류·전도 세 가지 열이 동시에 작용하며, **표시 온도와 실제 온도는 거의 언제나 다르다.**

## 종류와 선택

| 종류 | 가열 방식 | 온도 균일성 | 갈변 | 적합한 것 | 한계 |
|---|---|---|---|---|---|
| 일반(정적) 오븐 | 상·하 히터의 복사 | 낮음 (위아래 차이 큼) | 위쪽 우선 | 케이크, 수플레, 커스터드 | 랙 위치에 결과가 좌우된다 |
| 컨벡션 오븐 | 히터 + 팬 강제 대류 | 높음 | 전면 균일, 빠름 | 쿠키 여러 판, 로스트, 채소 | 가벼운 반죽이 날린다 |
| 스팀 오븐 | 대류 + 증기 주입 | 높음 | 조절 가능 | 빵(초기 증기), 재가열, 생선 | 비싸고 물탱크 관리 |
| 에어프라이어 | 소형 강제 대류 | 높음 | 매우 빠름 | 소량 튀김 대체, 재가열 | 용량이 작고 소음 |
| 미니 오븐(10~20L) | 노출 히터 복사 | 매우 낮음 | 겉만 탄다 | 토스트, 데우기 | 베이킹에 부적합 |

| 용량 | 실제 가용 | 감당 가능한 것 |
|---|---|---|
| 10~20L | 트레이 1장 | 토스트, 소량 그라탱 |
| 25~40L | 트레이 1~2장 | 쿠키, 파운드케이크, 채소 로스트, 통닭 1마리 |
| 50L 이상(빌트인) | 트레이 2~3장 | 빵, 대형 로스트, 여러 판 동시 |

## 사용법

오븐 안에서 열은 세 경로로 전달된다. **복사**(히터와 벽면에서 직접), **대류**(뜨거운 공기의 흐름), **전도**(팬·베이킹스톤에서 재료로 직접). 공기는 열용량이 매우 낮아서 180°C 오븐에 손을 잠깐 넣어도 데지 않지만, 같은 온도의 금속 팬을 만지면 즉시 화상을 입는다. **오븐 요리의 결과를 실제로 좌우하는 것은 공기 온도가 아니라 팬의 재질과 색이다.** 검고 무광인 팬은 복사를 잘 흡수해 바닥이 빨리 갈변하고, 밝고 광택 있는 팬은 반사해 늦게 갈변한다.

| 온도대 | 지배적으로 일어나는 일 | 대표 조리 |
|---|---|---|
| 60~90°C | 단백질 변성, 갈변 없음 | 커스터드, 저온 로스트, 요거트 |
| 100~130°C | 수분 증발이 전부 | 머랭 건조, 과일 말리기 |
| 140~170°C | 마이야르 반응이 본격화 | 저온 장시간 로스트, 파운드케이크 |
| 170~200°C | 갈변과 팽창이 균형 | 대부분의 베이킹 |
| 200~240°C | 표면 급속 갈변, 오븐 스프링 | 빵, 피자, 채소 로스트 |
| 브로일(그릴) | 위쪽 복사만 지배 | 그라탱, 마무리 색내기 |

| 항목 | 기준 | 이유 |
|---|---|---|
| 예열 | 알림이 울린 뒤 **추가 10~15분** | 알림은 공기 온도만 보고 울린다. 벽·랙·유리가 데워져야 온도가 안정된다 |
| 실제 온도 확인 | 오븐용 온도계를 넣어둔다 | 가정 오븐은 설정값 대비 ±15~25°C로 진동하고 평균값도 어긋난다 |
| 랙 위치 | 중단이 기본, 바닥 바삭함이 필요하면 하단, 색내기는 상단 | 복사원과의 거리 차이 |
| 컨벡션 변환 | 온도를 15~20°C 낮추거나 시간을 20~25% 줄인다 | 강제 대류가 열전달을 크게 높인다 |
| 문 열기 | 최소화. 열면 20~30°C가 즉시 떨어진다 | 회복에 수 분이 걸리고 그동안 팽창이 멈춘다 |
| 공기 흐름 | 팬과 벽 사이 3~5cm 확보, 트레이를 벽에 붙이지 않음 | 대류가 막히면 그 부분만 덜 익는다 |
| 회전 | 절반 시점에 트레이 앞뒤를 돌린다 | 가정 오븐에 완전히 균일한 오븐은 없다 |

**호일을 덮으면 빨리 익는다는 것은 반대다.** 알루미늄 호일은 복사열을 반사하므로 **갈변을 늦추려고** 덮는 것이다. 익는 속도 자체는 오히려 느려진다.

고기의 익힘·안전 온도는 [[육류 (개요)]]가 정본이며, 판단은 오븐 설정 온도가 아니라 중심부 온도로 한다. 측정 도구는 [[온도계]]를 참조한다.

## 관리와 보관

| 대상 | 방법 | 주기 | 주의 |
|---|---|---|---|
| 내부 벽·바닥 | 베이킹소다 + 물 페이스트를 발라 하룻밤, 젖은 천으로 제거 | 1~2개월 | 히터·팬 개구부에는 바르지 않는다 |
| 유리문 | 식초물 분무 후 카드로 긁어내기 | 1~2개월 | 연마재 금지 |
| 랙 | 뜨거운 물 + 주방세제에 담가 불림 | 사용 후 | — |
| 팬·트레이 | 눌어붙음은 물+베이킹소다를 끓여 제거 | 사용 후 | — |
| 셀프클리닝 | 400~500°C로 잔여물을 재로 만듦 | 연 1~2회 | **환기 필수. 조류는 실외로 옮긴다.** 고온으로 부품 수명이 준다 |
| 오븐 온도계 | 얼음물로 검증 | 반년 | — |

**셀프클리닝은 편하지만 부담이 큰 기능이다.** 문 잠금장치와 온도 센서에 열 스트레스를 주고, 이 기능 사용 직후 고장이 나는 사례가 흔하다. 평소 베이킹소다 청소를 하는 편이 오븐을 오래 쓴다.

**폐기·수리 신호**: 설정 온도와 실제 온도의 차이가 30°C를 넘고 일정하지도 않을 때(센서 또는 서모스탯 불량), 문 패킹이 경화되어 열이 새어 나올 때, 컨벡션 팬에서 금속 마찰음이 날 때.

## 핵심 포인트

**오븐 온도계 하나가 오븐 교체보다 낫다.** 설정 180°C에서 실제로 160°C나 200°C가 나오는 오븐이 흔하다. 한 번 측정해서 오차를 알면 그만큼 보정해서 쓰면 된다. 원인을 모른 채 레시피만 바꾸는 것이 가장 비효율적이다.

**컨벡션은 만능이 아니다.** 강제 대류는 표면을 빨리 말리므로 로스트와 쿠키에는 유리하지만, 수플레·시폰·슈처럼 구조가 굳기 전에 부푸는 반죽은 표면이 먼저 굳어 제대로 오르지 못한다.

**예열은 "온도 도달"이 아니라 "축열 완료"다.** 오븐 벽과 랙이 데워져야 문을 열었다 닫아도 온도가 빨리 회복된다. 피자·빵에 베이킹스톤을 쓸 때는 최소 30~45분 예열해야 의미가 있다.

**전자레인지가 영양을 파괴한다는 통설은 근거가 없다.** 오히려 가열 시간이 짧아 수용성 비타민 손실이 적은 편이다. 오븐과 전자레인지의 차이는 영양이 아니라 표면 건조와 갈변의 유무다.
