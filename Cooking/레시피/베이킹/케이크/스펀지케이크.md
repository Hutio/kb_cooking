# 스펀지케이크 (제노와즈)

## 주요 재료 (지름 18cm 원형 틀 1개)

### 반죽
- 달걀 4개 (M 사이즈, 200g)
- 설탕 100g
- 박력분 100g
- 버터 40g (또는 식용유)
- 우유 20ml
- 바닐라 익스트랙 1/2t (선택)
- 소금 한 꼬집

## 조리법

### 1단계: 준비 (10분)
1. 오븐을 170°C로 예열
2. 케이크 틀 바닥과 옆면에 유산지 깔기
3. 박력분은 2번 체로 거르기 (부드럽게)
4. 버터와 우유를 함께 중탕으로 녹여 40°C 유지
5. 달걀은 실온에 30분 미리 꺼내두기 (차가우면 안 됨)

### 2단계: 달걀 거품 내기 (핵심! 15분)
1. 큰 볼에 달걀 4개 + 설탕 100g + 소금 넣기
2. 핸드믹서 저속으로 섞다가 중속으로 전환
3. 중탕(60°C 물)하며 거품 내기 (달걀물이 따뜻해지면 거품 잘 남)
4. 달걀물이 미지근해지면 중탕에서 내리기
5. 고속으로 5분간 휘핑 (거품이 하얗고 묵직해짐)
6. 저속으로 2분 정리 (큰 기포 제거, 거품 안정화)
7. **리본 테스트**: 거품을 떨어뜨렸을 때 5초간 자국이 남으면 완성

### 3단계: 가루 섞기 (조심히!)
1. 체 친 박력분을 3번에 나눠 넣기
2. 주걱으로 바닥에서 떠올리듯 섞기 (자르듯 섞으면 거품 꺼짐)
3. 가루가 보이지 않을 정도만 섞기 (과도하게 섞으면 거품 손실)
4. 바닐라 익스트랙 넣기

### 4단계: 버터 섞기
1. 반죽 1국자를 버터+우유 볼에 넣어 섞기 (유화)
2. 유화된 버터를 반죽에 부어 빠르게 섞기
3. 주걱으로 15-20회 정도만 섞기 (버터가 고루 퍼지게)

### 5단계: 굽기
1. 틀에 반죽을 20cm 높이에서 부어 기포 제거
2. 틀을 10cm 높이에서 2-3번 톡톡 쳐서 큰 기포 빼기
3. 170°C 오븐에서 30-35분 굽기
4. **테스트**: 이쑤시개를 찔러 반죽이 안 묻어나면 완성
5. 오븐에서 꺼내 15cm 높이에서 한 번 떨어뜨려 열기 빼기 (쪼그라들기 방지)
6. 틀에서 바로 꺼내 식힘망에 올려 식히기

## 조리 팁

**달걀 거품이 전부**: 스펀지케이크는 베이킹파우더 없이 달걀 거품만으로 부풀립니다. 거품이 부족하면 케이크가 쪼그라들고 퍽퍽합니다. 리본 테스트 통과할 때까지 충분히 휘핑하세요.

**중탕의 마법**: 달걀을 중탕하며 휘핑하면 거품이 2배 이상 빨리, 더 안정적으로 만들어집니다. 단, 너무 뜨거우면 달걀이 익으니 60°C 유지하세요. 손으로 만졌을 때 미지근하면 적당합니다.

**가루 섞기 = 폭탄 조심**: 가루를 섞는 순간부터 거품이 꺼지기 시작합니다. 빠르고 정확하게, 최소한만 섞으세요. 100% 섞이지 않아도 오븐에서 익으며 섞입니다. 과도한 섞기는 실패의 지름길입니다.

**버터의 역할**: 버터는 촉촉함과 풍미를 더하지만, 거품을 가라앉힙니다. 반죽 일부를 버터에 먼저 섞어 유화시킨 뒤 넣어야 거품 손실이 적습니다. 식용유를 쓰면 더 쉽지만 풍미는 떨어집니다.

**오븐 온도 정확히**: 스펀지케이크는 온도에 민감합니다. 너무 높으면 겉만 타고 속은 설익고, 너무 낮으면 쪼그라듭니다. 170°C가 황금 온도이며, 오븐 온도계로 확인하세요.

**쪼그라들지 않으려면**: ①충분한 거품 ②오븐에서 꺼내자마자 한 번 떨어뜨리기 ③바로 틀에서 빼기 ④뒤집지 않고 세우기. 이 4가지만 지키면 쪼그라들지 않습니다.

**생크림 케이크 만들기**: 스펀지를 2-3등분으로 자르고, 생크림(휘핑크림 200ml + 설탕 20g 휘핑)과 과일을 샌드하면 생크림 케이크가 됩니다.

**하루 숙성**: 스펀지는 구운 직후보다 하루 숙성시킨 게 촉촉하고 맛있습니다. 랩으로 감싸 실온 보관 후 다음 날 사용하세요.

## 관련 레시피
- 생크림 케이크 - 스펀지 + 생크림 샌드
- 시폰케이크 - 더 부드러운 케이크
- [[쿠키]] - 베이킹 입문
- 머핀 - 간단한 베이킹

## 유래와 역사

스펀지케이크의 원형은 16세기 이탈리아 제노바에서 탄생한 **제노와즈(Génoise)**다. 달걀과 설탕만으로 부풀리는 기법은 당시 혁신적이었고, 이후 프랑스로 전해져 제과의 기본이 됐다. 18세기 영국에서 베이킹파우더가 등장하기 전까지 케이크를 부풀리는 유일한 방법이 달걀 거품이었다. 일본에서는 메이지 시대에 카스텔라(포르투갈 영향)와 함께 스펀지케이크 문화가 정착했고, 한국의 생크림 케이크(일명 '케이크')는 이 일본식 제노와즈를 기반으로 발전했다. 크리스마스 케이크, 생일 케이크의 베이스가 되는 가장 범용적인 케이크 반죽이다.

## 응용 변형

### 1인분 조절 (12cm 틀)
- 달걀 2개, 설탕 50g, 박력분 50g, 버터 20g, 우유 10ml
- 굽기 시간 20-25분으로 단축

### 재료 대체
- **버터 → 식용유**: 포도씨유나 카놀라유 40ml. 풍미는 떨어지지만 더 촉촉하고 가볍다
- **박력분 일부 → 코코아 파우더**: 박력분 80g + 코코아 파우더 20g = 초코 스펀지. 코코아가 수분을 흡수하므로 우유를 10ml 추가
- **박력분 일부 → 녹차 가루**: 박력분 90g + 말차 파우더 10g = 녹차 스펀지

### 활용 변형
- **딸기 쇼트케이크**: 스펀지 3단 + 생크림 + 딸기 슬라이스 샌드
- **티라미수 베이스**: 스펀지를 1cm 두께로 잘라 에스프레소 시럽에 적셔 사용
- **트라이플**: 스펀지를 큐브로 잘라 과일, 커스터드, 생크림과 층층이 쌓기

### 실패 구출법
- **쪼그라들었을 때**: 케이크를 잘라 트라이플이나 케이크팝으로 변신. 부서진 스펀지 + 크림치즈 + 초콜릿 코팅 = 케이크팝
- **속이 덜 익었을 때**: 170°C에서 5분씩 추가 굽기. 윗면이 탈 것 같으면 호일 덮기
- **표면이 갈라짐**: 오븐 온도가 너무 높았던 것. 갈라진 면을 아래로 뒤집어 생크림으로 덮으면 보이지 않음

### 보관
- 랩으로 감싸 실온 2일, 냉장 4일, 냉동 3주
- 냉동 스펀지는 냉장에서 4시간 해동 후 사용. 반해동 상태에서 자르면 깔끔하게 잘린다
