# 베이킹 (Baking)

베이킹은 밀가루, 계란, 설탕, 버터를 기본으로 한 제과·제빵입니다. 정확한 계량과 온도 관리가 성공의 핵심입니다.

## 카테고리별 베이킹

### 빵 (Bread)
- 식빵 - 기본 흰 빵
- 바게트 - 프랑스 바삭한 빵
- 크루아상 - 버터 층층이
- 베이글 - 쫄깃한 고리 빵

### 케이크 (Cake)
- 스펀지 케이크 - 폭신한 기본 케이크
- 파운드 케이크 - 버터 케이크
- 치즈케이크 - 크림치즈 케이크
- 초콜릿 케이크 - 진한 초콜릿

### 쿠키 (Cookies)
- 초코칩 쿠키 - 클래식 쿠키
- 마카롱 - 프랑스 샌드 쿠키
- 브라우니 - 촉촉한 초콜릿
- 스콘 - 영국식 비스킷

## 베이킹 기본

### 필수 재료
- **밀가루**: 박력분(케이크), 중력분(쿠키), 강력분(빵)
- **계란**: 구조, 유화, 기포
- **설탕**: 단맛, 수분 유지
- **버터**: 고소함, 층

### 팽창제
- **베이킹파우더**: 산 + 염기 반응
- **베이킹소다**: 염기, 산 필요
- **효모**: 발효로 CO2 생성
- **계란**: 기포 팽창

### 글루텐
- **형성**: 물 + 밀가루 → 글루텐
- **억제**: 과도한 반죽 금지 (케이크)
- **발달**: 주무르기 (빵)
- **없음**: 박력분 (약한 글루텐)

## 기법

### 크림법 (Creaming)
- 버터 + 설탕 크림화
- 공기 포함, 부드러움
- 쿠키, 파운드 케이크

### 거품법 (Foaming)
- 계란 + 설탕 거품
- 부피 증가
- 스펀지 케이크

### 반죽법 (Mixing)
- 재료 섞기만
- 글루텐 최소
- 머핀, 비스킷

### 층 만들기 (Laminating)
- 반죽 + 버터 층층이
- 크루아상, 파이

## 오븐 사용

### 예열
- 충분히 예열 (15-20분)
- 온도계로 확인

### 온도
- 케이크: 170-180°C
- 쿠키: 180-190°C
- 빵: 200-220°C

### 위치
- 중간 선반 (균일 열)
- 윗불·아랫불 조절

## 베이킹 팁

### 계량
- 저울 사용 (정확성)
- 밀가루: 체에 거르기
- 계란: 실온

### 반죽
- 과하게 섞지 않기
- 글루텐 최소 (케이크)
- 충분히 발효 (빵)

### 판별
- 이쑤시개 테스트 (케이크)
- 노릇한 색 (쿠키)
- 빵: 두드려 공명음

## 보관
- **케이크**: 냉장 3-5일, 냉동 3개월
- **쿠키**: 밀폐 용기 1주일
- **빵**: 실온 2-3일, 냉동 1개월
