# 일식 (개요)

> 다시(出汁)의 감칠맛과 간장·미림·청주의 배합이 거의 모든 요리의 뼈대다. 조리 자체는 단순하고, 대신 재료 온도와 추출 온도 같은 눈에 안 보이는 변수가 결과를 가른다.

## 시작하기

일식은 국물 하나만 잡으면 나머지가 따라온다. 아래 순서를 권한다.

1. **[[육수]]** — 다시마와 가다랑어포의 추출 온도가 왜 다른지 먼저 읽는다. 일식 국물 문서 전부가 이 값을 참조한다.
2. **[[우동]]** — 다시를 뽑아 간을 맞추는 가장 짧은 실습. 국물이 되면 소바·자루소바는 응용이다.
3. **[[규동]]** 또는 **[[오야코동]]** — 간장·미림·설탕·다시의 기본 배합(와리시타)을 익힌다. 덮밥 네 종류가 전부 이 배합의 변형이다.
4. **[[돈까스]]** → **[[가츠동]]** — 튀김 온도 관리와 여열 조리를 익히고, 그 결과물을 덮밥으로 넘긴다.
5. **[[텐푸라]]** — 튀김옷을 덜 섞는 감각. 여기까지 오면 [[텐동]]은 조립일 뿐이다.
6. **[[초밥]]·[[회]]** — 조리가 아니라 손질과 안전의 영역이다. 생식 기준은 [[연어]] 문서를 먼저 본다.

- [[텐동]] — 텐푸라를 올리고 진한 간장 소스를 끼얹은 덮밥

- [[우동]] — 다시 국물에 마는 굵은 밀가루 면
- [[소바]] — 메밀면을 쯔유에 찍어 먹는 면
- [[자루소바]] — 급랭한 메밀면을 채반에 담아 내는 냉소바

## 일식의 맛 구조

### 다시가 기준선이다

일식 국물의 감칠맛은 다시마의 글루탐산과 가다랑어포의 이노신산을 함께 쓰는 데서 나온다. 두 성분을 같이 쓰면 감칠맛이 각각의 합이 아니라 몇 배로 올라간다. **재료별 추출 온도와 시간은 [[육수]]가 정본이다** — 다시마와 가다랑어포는 적정 온도가 서로 다르고, 이 둘을 한 문장에 뭉뚱그리면 반드시 틀린 값이 나온다.

### 기본 조미 4종

| 조미료 | 역할 | 주의 |
|---|---|---|
| 간장 | 짠맛·감칠맛·색 | 관동은 진한 간장, 관서는 연한 간장 |
| 미림 | 단맛·윤기·잡내 제거 | 혼미림과 미림풍 조미료는 다른 물건이다 ([[미림]]) |
| 청주 | 잡내 제거·풍미 | 요리용 청주는 소금이 든 제품이 있어 간을 다시 본다 |
| 다시 | 감칠맛의 바탕 | 국물 요리의 기준선 |

### 지역별 성향

| 지역 | 간장 | 대표 |
|---|---|---|
| 관동(도쿄) | 진한 간장, 국물이 짙다 | 니기리 스시, 쇼유 라멘 |
| 관서(오사카) | 연한 간장, 국물이 맑다 | 오시즈시, 관서식 우동 |
| 홋카이도 | 된장 기반 | 미소 라멘 |
| 규슈 | 단맛이 강하다 | 돈코츠 라멘 |
