# 일식 (Japanese Cuisine)

일식은 깔끔하고 섬세한 맛, 신선한 재료 본연의 맛을 중시합니다. 감칠맛(다시) 기반의 국물과 간결한 조리법이 특징입니다.

## 일식 특징

### 조리 철학
- **제철 재료**: 제철의 신선함
- **단순함**: 최소한의 조리
- **보존**: 재료 본연의 맛
- **시각**: 아름다운 플레이팅

### 맛의 특징
- **감칠맛**: 다시 (가다랑어포 + 다시마)
- **깔끔함**: 기름 적게
- **단맛 약함**: 미림, 설탕 소량
- **신선함**: 생선회, 생야채

### 필수 재료
- 간장, 미림, 사케
- 다시 (가다랑어포, 다시마)
- 된장 (미소)
- 생강, 와사비, 대파

## 다시 (Dashi)

### 기본 다시
- **가다랑어포 다시**: 이노신산 (감칠맛)
- **다시마 다시**: 글루탐산 (감칠맛)
- **혼합 다시**: 시너지 효과 (8배)

### 만들기
1. 다시마 찬물 30분 불리기
2. 중불로 가열, 끓기 직전 다시마 건지기
3. 가다랑어포 넣고 1분
4. 체로 거르기

## 소스·양념

### 데리야끼 소스
- 간장 + 미림 + 설탕 + 사케
- 구이, 덮밥

### 폰즈 (Ponzu)
- 간장 + 유자즙 (또는 레몬)
- 샤부샤부, 구이

### 텐츠유 (Tentsuyu)
- 다시 + 간장 + 미림
- 덴푸라 디핑

### 와사비·생강
- 회와 초밥에 필수
- 비린내 제거, 항균

## 조리 팁

### 초밥 만들기
1. 초밥용 쌀 (단립종)
2. 초 (식초 + 설탕 + 소금)
3. 밥 한 김 식히며 초 섞기
4. 생선회 + 와사비

### 텐푸라 튀기기
1. 튀김옷 차갑게 (얼음물)
2. 살짝만 섞기 (글루텐 최소)
3. 170-180°C 기름
4. 한 번에 조금씩

### 라멘 국물
- 돈코츠: 돼지뼈 12시간 끓임
- 미소: 된장 베이스
- 쇼유: 간장 베이스

## 일식 문화

### 이타다키마스
- 식사 전: "잘 먹겠습니다"
- 식사 후: "잘 먹었습니다" (고치소사마)

### 젓가락 예절
- 음식 찍지 않기
- 젓가락 세우지 않기
- 그릇에서 그릇으로 건네지 않기

### 그릇 사용
- 작은 그릇 들고 먹기
- 왼손으로 받치기
