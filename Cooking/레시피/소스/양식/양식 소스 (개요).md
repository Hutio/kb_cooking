# 양식 소스 (European Sauces)

양식 소스는 프랑스 요리를 중심으로 체계화된 5대 모체 소스(Mother Sauces)를 기반으로 합니다. 루(Roux), 유화(Emulsion), 환원(Reduction) 등의 기법을 사용합니다.

## 5대 모체 소스

### [[베샤멜]] (Béchamel)
- 루(버터+밀가루) + 우유
- 그라탱, 크림 파스타, 라자냐
- 파생: 모르네(치즈), 수비즈(양파)

### [[홀랜다이즈]] (Hollandaise)
- 계란 노른자 + 버터 유화
- 에그 베네딕트, 아스파라거스
- 파생: 베어네즈(타라곤)

### [[토마토 소스]] (Tomato)
- 토마토 + 미르푸아 + 허브
- 파스타, 피자, 스튜
- 파생: 마리나라, 아라비아타

### 벨루테 (Velouté)
- 루 + 화이트 스톡(닭, 생선, 송아지)
- 크림 수프, 생선 요리
- 파생: 알레망드(계란+크림)

### 에스파뇰 (Espagnole)
- 루 + 브라운 스톡
- [[데미글라스]]로 환원
- 스테이크, 육류 소스

## 유화 소스

### [[마요네즈]] (Mayonnaise)
- 계란 노른자 + 기름 유화
- 샌드위치, 샐러드 드레싱
- 파생: [[타르타르 소스]], 아이올리

### 비네그레트 (Vinaigrette)
- 기름 + 식초 (3:1 비율)
- 샐러드 드레싱
- 파생: 발사믹, 머스타드

## 크림 소스

### [[알프레도 소스]]
- 크림 + 파르메산 치즈 + 버터
- 크림 파스타 (Fettuccine Alfredo)

### 카르보나라
- 계란 + 파르메산 + 베이컨
- 파스타 (Spaghetti Carbonara)

## 토마토 베이스 소스

### 마리나라
- 토마토 + 마늘 + 바질
- 간단한 파스타, 피자

### 아라비아타
- 토마토 + 마늘 + 고추
- 매운 파스타

### 볼로네제
- 토마토 + 고기 미트소스
- 라자냐, 스파게티

## 기타 클래식 소스

### [[페스토]] (Pesto)
- 바질 + 잣 + 파르메산
- 파스타, 샌드위치

### [[케첩]] (Ketchup)
- 토마토 + 설탕 + 식초
- 범용 디핑 소스

### [[발사믹 소스]]
- 발사믹 식초 환원
- 샐러드, 스테이크

## 제작 기법

### 루 (Roux)
- 버터 + 밀가루 1:1
- 화이트 루(1-2분), 블론드 루(3-5분), 브라운 루(15-20분)

### 유화 (Emulsion)
- 기름 + 물 혼합 (계란 노른자가 유화제)
- 천천히 기름 추가하며 휘젓기

### 환원 (Reduction)
- 액체 졸여 농축
- 맛과 향 집중, 농도 증가

## 조리 팁

### 덩어리 방지
- 루에 액체 조금씩 추가
- 계속 저으며 끓이기

### 유화 분리 방지
- 온도 너무 높지 않게 (60-70°C)
- 천천히 기름 추가

### 맛 균형
- 산미: 레몬즙, 와인
- 감칠맛: 치즈, 버터
- 허브: 타임, 월계수잎
