# 발사믹 소스 (Balsamic Reduction)

> 발사믹 식초를 절반까지 졸여 시럽 상태로 만든 소스. 재료가 사실상 하나뿐이고, 하는 일은 물을 날려 산과 당을 농축하는 것 전부다.

## 재료

### 주재료 (약 100ml)

- 발사믹 식초 200ml
- 꿀 2큰술 (또는 설탕 3큰술)

### 향미 (선택, 모두 건져낸다)

- 마늘 2쪽 (껍질째)
- 로즈마리 1줄기
- 통후추 5알
- 레드와인 50ml

## 만드는 법

1. **준비 (2분)** — 바닥이 넓은 냄비에 발사믹 식초 200ml를 붓고 향미 재료를 넣는다. 넓은 냄비를 쓰는 이유는 표면적이 넓을수록 고르게 졸아들기 때문이다.
2. **졸이기 (15~20분)** — 중불에서 끓이기 시작해 끓으면 약불로 낮춘다. 가끔 저으며 양이 절반~3분의 1이 될 때까지 졸인다. **크게 부글거리면 불이 세다는 신호다.**
3. **농도 확인 (1분)** — 찬 숟가락에 묻혀 기울였을 때 천천히 흘러내리면 완성이다. 식초보다 걸쭉하고 시럽보다는 묽은 상태다. 식으면 눈에 띄게 더 되직해지므로 **약간 묽다 싶을 때 불을 끈다.**
4. **마무리 (2분)** — 불을 끄고 꿀 2큰술을 섞은 뒤 마늘·로즈마리·통후추를 건진다. 완전히 식혀 병에 담는다.

## 핵심 포인트

**비싼 발사믹은 졸이지 않는다.** 12년 이상 숙성한 아체토 발사미코 트라디치오날레는 이미 졸여진 포도즙(모스토 코토)을 오래 숙성시킨 것이라, 그 자체로 시럽 상태이고 그 향을 얻으려고 값을 치른 것이다. 다시 끓이면 섬세한 향이 날아간다. 졸이는 용도는 값싼 모데나 IGP 발사믹으로 충분하다.

**타는 맛과 쓴맛은 다른 실패다.** 센 불에서 급하게 졸이면 바닥에 눌어 탄맛이 나고, 너무 오래 졸이면 당이 캐러멜을 지나 쓴맛으로 간다. 약불 15~20분이 두 실패 사이의 구간이다.

**꿀은 불을 끄고 넣는다.** 꿀의 향 성분은 휘발성이고 과당은 설탕보다 낮은 온도에서 갈변한다. 졸이는 내내 넣어 두면 향은 사라지고 쓴맛만 남는다.

**식으면 30% 이상 되직해진다.** 굳어 버렸다면 물을 1작은술씩 넣고 약불에서 다시 데워 푼다.

## 활용법

| 용도 | 쓰는 법 |
|---|---|
| 카프레제 | 모차렐라와 토마토 위에 실처럼 두른다 |
| 스테이크·구운 닭 | 접시에 낸 뒤 마지막에 뿌린다 |
| 로스팅 채소 | 오븐에서 꺼낸 직후 뿌려 윤기를 낸다 |
| 딸기·바닐라 아이스크림 | 산미가 단맛을 끌어올린다 |
| 샐러드 드레싱 | 올리브유와 2:1로 섞는다 |

## 보관과 재가열

냉장 0~4°C에서 3개월 이상. 산도가 높아 미생물이 자라기 어렵다. 냉장하면 굳으므로 쓰기 20분 전에 꺼내 두거나 병째 미지근한 물에 담근다.
