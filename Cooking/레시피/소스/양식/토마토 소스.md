# 토마토 소스 (Tomato Sauce)

## 재료 (4-6인분 파스타용)

**기본 재료**
- 홀토마토 통조림 800g (2캔)
- 올리브 오일 4T
- 양파 1개 (중간 크기)
- 마늘 6쪽
- 토마토 페이스트 2T
- 설탕 1T
- 소금 1t
- 후추 1/2t

**부재료 (향신료)**
- 바질 (신선한 것) 10장 (또는 건조 바질 1t)
- 오레가노 (건조) 1t
- 타임 1/2t
- 베이리프 2장
- 레드와인 50ml (선택)

## 조리법

### 1단계: 재료 준비
1. 양파를 잘게 다지기 (0.5cm 큐브)
2. 마늘을 얇게 슬라이스 또는 다지기
3. 홀토마토는 손으로 으깨거나 블렌더로 곱게 갈기

### 2단계: 베이스 볶기
1. 팬에 올리브 오일 4T를 중불에서 가열
2. 양파를 넣고 5분간 볶기 (투명해질 때까지)
3. 마늘 추가하고 1분간 더 볶기 (갈색 되면 안 됨)
4. 토마토 페이스트 2T 넣고 1분간 볶아 신맛 날리기

### 3단계: 토마토 추가
1. 으깬 홀토마토 800g 붓기
2. 토마토 캔에 물 100ml 넣어 남은 토마토 씻어서 추가
3. 설탕 1T, 소금 1t, 후추 1/2t로 간하기
4. 레드와인 50ml 추가 (선택, 깊은 맛)

### 4단계: 허브 추가
1. 바질, 오레가노, 타임, 베이리프 넣기
2. 중불에서 끓이기 시작
3. 끓으면 약불로 줄이고 뚜껑 살짝 열어두고 졸이기

### 5단계: 졸이기 (30-45분)
1. 약불에서 30-45분간 졸이기 (가끔 저어주기)
2. 토마토의 신맛이 날아가고 단맛이 나올 때까지
3. 농도는 "숟가락으로 젓을 때 자국이 남는 정도"
4. 베이리프 건져내기

### 6단계: 마무리
1. 맛을 보고 소금, 설탕으로 간 조절
2. 신선한 바질을 잘게 찢어 넣기
3. 올리브 오일 1T 추가로 윤기나게

## 조리 팁

1. **토마토 선택**: 홀토마토 통조림이 베스트입니다. 산 마르자노(San Marzano) 토마토가 최고지만 비쌉니다. 일반 홀토마토 통조림도 충분히 맛있습니다. 다진 토마토는 물이 많아서 비추천입니다.

2. **신맛 제거**: 토마토의 신맛이 싫다면 설탕을 2T까지 늘리세요. 당근 1/2개를 갈아 넣어도 자연스러운 단맛이 납니다. 오래 졸이면 신맛이 자연스럽게 날아갑니다.

3. **농도 조절**: 너무 묽으면 뚜껑을 열고 더 졸이세요. 너무 되직하면 물이나 파스타 삶은 물을 추가하세요. 파스타용은 약간 묽게, 피자용은 되직하게 만드세요.

4. **보관법**: 냉장 보관 시 5일, 냉동 보관 시 3개월 갑니다. 소분해서 얼리면 편리합니다. 해동은 냉장고에서 천천히 하세요.

5. **깊은 맛의 비밀**: 레드와인, 발사믹 식초(1T), 안초비(2마리 다진 것)를 추가하면 감칠맛이 크게 향상됩니다. 육수를 조금 넣어도 좋습니다.

## 응용 레시피

### 아라비아타 (매운 버전)
레드 페퍼 플레이크 1T 추가

### 마리나라 (심플 버전)
허브 제외, 마늘+올리브 오일+토마토만 사용

### 볼로네제 소스
소고기 다짐육 500g을 먼저 볶고 토마토 소스 추가
