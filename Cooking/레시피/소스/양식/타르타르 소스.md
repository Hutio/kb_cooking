# 타르타르 소스 (Tartar Sauce)

## 재료 (4-6인분)

**기본 재료**
- 마요네즈 200g
- 피클 (딜 피클) 50g
- 케이퍼 2T
- 양파 (적양파 선호) 2T
- 레몬즙 1T
- 디종 머스타드 1t
- 설탕 1/2t
- 소금 1/4t
- 후추 1/4t

**부재료 (선택)**
- 파슬리 다진 것 1T
- 딜 (신선한 것) 1T
- 마늘가루 1/4t
- 핫소스 몇 방울

## 조리법

### 1단계: 재료 준비
1. 피클 50g을 잘게 다지기 (0.3cm 크기)
2. 케이퍼를 칼로 굵게 다지기
3. 양파를 아주 곱게 다지고 물에 5분 담갔다가 물기 제거 (매운맛 제거)
4. 파슬리, 딜도 곱게 다지기

### 2단계: 마요네즈 베이스
1. 볼에 마요네즈 200g 넣기
2. 레몬즙 1T 추가하고 섞기
3. 디종 머스타드 1t로 톡 쏘는 맛 더하기
4. 설탕 1/2t로 단맛 밸런스 맞추기

### 3단계: 재료 섞기
1. 다진 피클, 케이퍼, 양파 넣고 고루 섞기
2. 파슬리와 딸 추가 (허브 향)
3. 소금 1/4t, 후추 1/4t로 간하기
4. 핫소스 몇 방울로 킥 더하기 (선택)

### 4단계: 숙성
1. 밀폐용기에 담아 냉장고에 1시간 숙성
2. 재료들의 맛이 어우러지도록
3. 사용 전에 한 번 더 저어주기

## 조리 팁

1. **피클 선택**: 달콤한 피클보다는 딜 피클(새콤한 피클)이 타르타르 소스에 더 잘 어울립니다. 한국에서는 오이피클이나 코스트코 딜 피클이 좋습니다.

2. **물기 제거**: 피클과 케이퍼는 물기를 꼭 짜서 넣으세요. 물기가 많으면 소스가 묽어지고 맛도 싱거워집니다.

3. **양파 처리**: 생양파를 그대로 넣으면 너무 맵습니다. 물에 5-10분 담갔다가 쓰면 매운맛이 빠지고 아삭한 식감만 남습니다.

4. **보관법**: 냉장 보관 시 5-7일 갑니다. 시간이 지나면 피클 물이 빠져서 묽어지니 만들어서 3일 내 먹는 것이 가장 맛있습니다.

5. **직접 마요네즈**: 시판 마요네즈 대신 직접 만든 마요네즈를 쓰면 맛이 훨씬 좋습니다. 레몬즙을 넉넉히 넣은 마요네즈가 타르타르에 잘 어울립니다.

## 활용법

- **생선 튀김**: 피쉬 앤 칩스의 클래식 소스
- **새우 요리**: 새우튀김, 팝콘 새우에 찍어먹기
- **샌드위치**: 참치 샌드위치, 피쉬 버거의 소스
- **샐러드**: 새우 샐러드, 게살 샐러드 드레싱

## 응용 레시피

### 레몬 타르타르
레몬즙을 2T로 증량 + 레몬 제스트 1t 추가

### 스파이시 타르타르
핫소스 1T + 카이엔 페퍼 1/4t 추가

### 허브 타르타르
신선한 딜, 파슬리, 차이브를 각각 1T씩 추가
