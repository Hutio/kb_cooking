# 아시아 소스 (Asian Sauces)

동남아시아와 일본의 소스는 발효 어장(피시소스), 감귤(라임, 유자), 신선한 허브(고수, 레몬그라스)를 활용한 밝고 상큼한 맛이 특징입니다.

## 동남아 소스 (Southeast Asian)

### 피시소스 (Fish Sauce)
- 멸치·까나리 발효액
- 베트남(젓갈), 태국(젓갈)
- 팟타이, 똠양꿍, 볶음밥
- 짠맛 + 감칠맛

### [[스위트 칠리]] (Sweet Chili Sauce)
- 고추 + 설탕 + 마늘 + 식초
- 태국 디핑 소스
- 월남쌈, 구운 고기, 해산물
- 매콤달콤

### [[칠리 소스]]
- 고추 + 마늘 (발효 또는 생)
- 사테, 볶음 요리
- 매운맛 강도 다양

### 땅콩 소스 (Peanut Sauce)
- 땅콩버터 + 코코넛 밀크 + 라임
- 인도네시아 사테, 가도가도
- 고소하고 크리미

## 베트남 소스

### 느억맘 디핑 (Nước Chấm)
- 젓갈 + 라임 + 설탕 + 물
- 월남쌈, 파전, 구운 고기
- 신맛 + 짠맛 + 단맛 균형

### 호이신 소스
- 콩 발효 + 설탕 + 향신료
- 쌀국수, 샌드위치
- 달콤하고 진함

## 태국 소스

### 똠양 페이스트
- 레몬그라스 + 갈랑갈 + 칠리
- 똠양꿍 베이스
- 신맛 + 매운맛 + 허브향

### 타마린드 소스
- 타마린드 + 설탕 + 피시소스
- 팟타이, 커리
- 신맛 + 단맛

## 일식 소스

### 데리야끼 소스
- 간장 + 미림 + 설탕
- 구이, 규동
- 달콤짭짤하고 광택

### 폰즈 (Ponzu)
- 간장 + 감귤즙 (유자, 스다치)
- 샤부샤부, 구이 디핑
- 상큼하고 짠맛

### 덴푸라 소스 (Tentsuyu)
- 다시 + 간장 + 미림
- 텐푸라 디핑
- 감칠맛 + 단맛

### 토기 소스 (Tonkatsu Sauce)
- 토마토 + 우스터 + 과일
- 돈까스, 돈까스
- 달콤하고 진함

## 조리 특징

### 신맛 활용
- 라임, 레몬, 타마린드
- 밝고 상큼한 풍미
- 느끼함 중화

### 허브 향
- 고수, 레몬그라스, 민트
- 신선하고 복합적
- 마지막에 추가

### 발효 감칠맛
- 피시소스, 새우페이스트
- 깊고 진한 맛
- 소량으로 강한 효과

## 기본 레시피

### 만능 느억맘 디핑
- 피시소스 2T + 라임즙 2T
- 설탕 2T + 물 4T
- 다진 마늘, 칠리

### 기본 데리야끼
- 간장 4T + 미림 4T
- 설탕 2T + 청주 2T
- 졸여서 농축

## 조리 팁

### 균형 잡기
- 단맛·신맛·짠맛 균등
- 피시소스는 소량씩 추가
- 라임즙 마지막에 (신선함)

### 허브 사용
- 신선한 것 사용
- 조리 마지막 투입
- 손으로 찢어 향 극대화
