# 칠리 소스

## 재료 (약 200ml)

**기본 재료**
- 청양고추 10개
- 홍고추 5개
- 마늘 8쪽
- 식초 80ml
- 설탕 3T
- 소금 1t
- 물 50ml

**부재료**
- 피시소스 1T
- 라임즙 2T
- 생강 1톨 (엄지손가락 크기)
- 고춧가루 1T (색상 보강)

## 조리법

### 1단계: 고추 준비
1. 청양고추와 홍고추를 세척하고 꼭지 제거
2. 매운맛 원하면 씨 포함, 순하게 하려면 씨 제거
3. 굵게 송송 썰기 (푸드프로세서 사용 가능)

### 2단계: 믹싱
1. 푸드프로세서에 고추, 마늘, 생강 넣기
2. 물 50ml 추가하고 곱게 갈기 (30초-1분)
3. 덩어리 없이 페이스트 상태로 만들기

### 3단계: 끓이기
1. 냄비에 갈아놓은 페이스트 넣기
2. 식초 80ml, 설탕 3T, 소금 1t 추가
3. 중불에서 저으며 10분간 끓이기

### 4단계: 마무리
1. 피시소스 1T로 감칠맛 강화
2. 라임즙 2T로 상큼함 추가
3. 고춧가루 1T로 색상 보강 (선택)
4. 걸쭉해질 때까지 5분 더 졸이기
5. 완전히 식힌 후 병에 담기

## 조리 팁

1. **매운맛 단계 조절**: 청양고추만 사용하면 극강 매운맛, 홍고추만 사용하면 순한 맛입니다. 비율을 조절해서 원하는 매운맛을 만드세요. 청양 5개 + 홍고추 10개가 중간 매운맛입니다.

2. **씨의 역할**: 고추씨는 매운맛의 80%를 차지합니다. 씨를 완전히 제거하면 색깔은 빨갛지만 맛은 순합니다. 매운맛은 원하지만 씨 질감은 싫다면 곱게 갈아주세요.

3. **농도 조절**: 물을 더 넣으면 묽은 소스(딥용), 물을 적게 넣으면 되직한 페이스트(양념용)가 됩니다. 딥소스는 물 100ml, 페이스트는 물 30ml로 조절하세요.

4. **발효 효과**: 만든 후 냉장고에 3일 숙성시키면 맛이 더 깊어지고 톡 쏘는 맛이 부드러워집니다. 바로 먹어도 되지만 3일 후가 피크입니다.

5. **보관법**: 살균한 유리병에 담아 냉장 보관하면 2개월 갑니다. 공기 접촉을 줄이려면 표면에 식용유를 살짝 두르세요. 곰팡이가 생기면 즉시 폐기하세요.

## 활용법

- **딥소스**: 만두, 튀김, 치킨 등에 찍어먹기
- **볶음 양념**: 새우볶음, 오징어볶음의 베이스
- **국물 요리**: 쌀국수, 해물탕에 한 스푼 추가로 깊은 맛
- **마리네이드**: 닭고기, 돼지고기 재울 때 사용
