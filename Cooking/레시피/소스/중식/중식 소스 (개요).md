# 중식 소스 (Chinese Sauces)

중식 소스는 감칠맛과 단짠 조합이 특징이며, 고온 볶기에 최적화되어 있습니다. 발효 조미료를 베이스로 빠르게 맛을 내는 것이 핵심입니다.

## 발효 베이스 소스

### [[간장 소스]]
- 중국 간장(老抽, 生抽) + 설탕 + 마늘
- 볶기, 조림, 면 요리
- 진간장(노추): 색 진하고 단맛
- 생간장(생추): 색 연하고 짠맛

### [[춘장 소스]]
- 춘장(춘장면장) + 설탕 + 야채
- 짜장면의 베이스
- 캐러멜화된 단맛

### 두반장 소스
- 두반장(辣豆瓣酱) + 마늘 + 생강
- 마파두부, 사천 볶음
- 매콤한 발효 풍미

## 감칠맛 소스

### [[굴소스]] (蠔油)
- 굴 추출물 + 설탕 + 간장
- 볶기, 쇠고기 브로콜리
- 진하고 달콤짭짤한 감칠맛

### XO소스
- 건새우, 가리비 + 햄 + 칠리
- 고급 해산물 소스
- 볶음, 딤섬 디핑

## 볶음 소스

### 칠리 소스
- 고추 + 마늘 + 식초
- 깐풍기, 라조기
- 매콤달콤

### 흑초 소스
- 중국 흑초(香醋) + 간장 + 설탕
- 탕수육, 딤섬 디핑
- 신맛 + 단맛 조화

### 깐풍 소스
- 간장 + 설탕 + 식초 + 고추
- 깐풍기, 새우 볶음
- 매콤달콤새콤

## 면 요리 소스

### 짜장 소스
- 춘장 + 돼지고기 + 야채
- 짜장면
- 구수하고 달콤

### 짬뽕 양념
- 고춧기름 + 해물 + 야채
- 짬뽕
- 얼큰하고 시원함

## 조리 기법

### 고온 빠른 조리
- 200°C 이상 웨이브
- 소스 마지막에 투입
- 빠르게 섞어 코팅

### 전분물 활용
- 감자전분 + 물 (1:3)
- 소스에 광택과 농도
- 마지막에 넣고 빠르게 섞기

### 향신료 베이스
- 마늘, 생강, 파 먼저 볶기
- 기름에 향 추출
- 재료 투입 후 소스

## 기본 중화 소스 레시피

### 만능 볶음 소스
- 간장 2T + [[굴소스]] 1T + 설탕 1T
- 물 3T + 전분물 약간
- 마늘, 생강 으깨기

### 탕수육 소스
- 설탕 3T + 식초 2T + 케첩 2T
- 물 1컵 + 전분물
- 파인애플, 양파, 당근

## 조리 팁

### 소스 투입 시점
- 재료 80% 익으면 소스 투입
- 강불에서 빠르게 섞기
- 전분물은 마지막 (30초)

### 윤기 내기
- 참기름 마지막에 둘러 넣기
- 전분물로 광택
- 재료와 소스 완전히 코팅
