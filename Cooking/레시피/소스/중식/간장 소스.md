# 중식 간장 소스 (Chinese Soy Sauce)

## 재료 (만능 베이스, 4인분)

**기본 재료**
- 진간장 4T
- 굴소스 2T
- 물 100ml
- 설탕 1.5T
- 전분물 (감자전분 1T + 물 2T)
- 참기름 1t

**향미 재료**
- 마늘 3쪽 (다진 것)
- 생강 1톨 (엄지손가락 크기, 다진 것)
- 대파 1대 (송송 썬 것)
- 청주 1T

**부재료 (선택)**
- 후추 1/4t
- 팔각 1개 (중식 향신료)
- 계피 가루 1/8t

## 조리법

### 1단계: 향 내기
1. 팬에 참기름 1t를 중불에서 가열
2. 다진 마늘과 생강 넣고 30초간 볶기 (갈색 되면 안 됨)
3. 대파 흰 부분 추가하고 10초 더 볶기
4. 향이 올라오면 즉시 다음 단계로

### 2단계: 소스 베이스
1. 진간장 4T와 굴소스 2T 넣기
2. 물 100ml 붓고 섞기
3. 청주 1T로 비린내 제거
4. 설탕 1.5T로 단맛 더하기
5. 팔각, 계피 가루 추가 (선택)

### 3단계: 끓이기
1. 중불에서 2-3분간 끓이기
2. 가끔 저어가며 향신료 맛 우러나게 하기
3. 팔각은 건져내기 (오래 두면 쓴맛)

### 4단계: 농도 맞추기
1. 전분물을 천천히 부으며 저어주기
2. 윤기나고 걸쭉한 소스로 만들기
3. 30초-1분 더 끓여서 전분 익히기
4. 대파 파란 부분 송송 썬 것으로 마무리

## 농도별 활용

### 묽은 버전 (볶음/비빔)
- 전분물 없이 사용
- 물 150ml로 증량
- 용도: 중식 볶음밥, 짬뽕밥, 해물볶음

### 되직한 버전 (찍어먹기/덮밥)
- 전분물 2T로 증량
- 물 80ml로 감량
- 용도: 만두 소스, 탕수육 소스, 중화 덮밥

### 진한 버전 (조림/구이)
- 굴소스 3T로 증량
- 설탕 2T로 증량
- 용도: 중식 갈비찜, 간장 닭고기, 두부조림

## 조리 팁

1. **굴소스의 역할**: 굴소스는 감칠맛의 핵심입니다. 중식 소스의 깊이는 굴소스에서 나옵니다. 한식 간장과의 가장 큰 차이점이 바로 굴소스입니다.

2. **전분 선택**: 감자전분이 가장 투명하고 윤기가 납니다. 옥수수 전분도 괜찮지만 약간 뿌옇습니다. 밀가루는 중식 소스에는 맞지 않습니다.

3. **팔각의 마법**: 팔각 1개만 넣어도 중식당 맛이 납니다. 하지만 오래 끓이면 쓴맛이 나니 2-3분 후 건져내세요. 팔각이 없으면 생략 가능합니다.

4. **보관법**: 냉장 보관 시 3-4일 갑니다. 전분이 들어가서 시간이 지나면 굳습니다. 재가열할 때 물을 조금 추가하세요.

5. **비린내 제거**: 해산물 요리에 쓸 때는 청주를 2T로 늘리고, 생강을 넉넉히 넣으세요. 생선 특유의 비린내를 잡아줍니다.

## 응용 레시피

### 깐풍기 소스
기본 레시피 + 고춧가루 2T + 식초 2T + 설탕 2T

### 짬뽕 소스
기본 레시피 + 고춧가루 3T + 고추기름 2T + 해물 육수 200ml

### 유린기 소스
기본 레시피 + 식초 3T + 설탕 2T + 대파 듬뿍
