# 간장 양념

## 재료 (만능 베이스, 4-6인분)

**기본 재료**
- 간장 4T
- 설탕 2T
- 다진 마늘 1T
- 참기름 1T
- 통깨 1T
- 물 2T

**부재료 (깊은 맛)**
- 청주 1T
- 후추 1/2t
- 생강즙 1t
- 대파 다진 것 2T

## 조리법

### 1단계: 기본 베이스
1. 볼에 간장 4T 넣기
2. 설탕 2T를 넣고 완전히 녹을 때까지 저어주기
3. 물 2T로 농도 조절

### 2단계: 향미 강화
1. 다진 마늘 1T 넣고 섞기
2. 청주 1T로 간장 특유의 짠맛 중화
3. 생강즙 1t로 깔끔한 뒷맛 만들기

### 3단계: 마무리
1. 대파 다진 것 2T 추가 (즉석 요리용)
2. 후추 1/2t로 향 더하기
3. 참기름 1T와 통깨 1T로 고소함 완성

## 농도별 활용

### 짙은 버전 (조림/볶음)
- 물 제외, 설탕 3T로 증량
- 졸이며 윤기나게
- 용도: 장조림, 멸치볶음, 어묵볶음

### 묽은 버전 (무침/비빔)
- 물 4T로 증량
- 식초 1T 추가 (새콤함)
- 용도: 오이무침, 콩나물무침, 숙주무침

### 진한 버전 (마리네이드)
- 물엿 2T 추가
- 배즙 2T로 연육
- 용도: 불고기, 갈비찜, 닭고기 재우기

## 조리 팁

1. **간장 선택**: 진간장은 색이 진하고 짠맛이 강합니다. 양조간장은 색이 연하고 깔끔합니다. 만능 양념은 양조간장 3T + 진간장 1T 비율이 좋습니다.

2. **단맛 조절**: 설탕 대신 물엿을 쓰면 윤기가 나고, 꿀을 쓰면 부드럽습니다. 올리고당은 덜 달고 건강하지만 특유의 맛이 있습니다.

3. **대파의 타이밍**: 바로 먹을 요리는 생대파를 넣고, 오래 보관할 양념은 대파를 빼세요. 대파가 들어가면 2-3일 내 사용해야 합니다.

4. **보관법**: 대파를 빼고 만들면 냉장고에서 2주 보관 가능합니다. 밀폐용기에 담고, 사용할 때마다 깨끗한 숟가락을 쓰세요.

5. **불 조절**: 조림 요리에 쓸 때는 약불에서 천천히 졸이세요. 센 불에서 졸이면 간장이 타서 쓴맛이 납니다. 은근히 조려야 윤기가 나고 맛이 깊어집니다.

## 응용 레시피

### 장조림 양념
기본 레시피 + 물 200ml + 통마늘 5개 + 청양고추 3개

### 불고기 양념
기본 레시피 + 배즙 3T + 양파즙 2T + 키위즙 1T (연육)

### 비빔밥 양념장
기본 레시피 + 고춧가루 1T + 식초 1T + 참기름 2T
