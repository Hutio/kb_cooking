# 한식 소스 (Korean Sauces)

한식 소스는 발효를 기반으로 한 깊고 구수한 맛이 특징입니다. [[된장]], 간장, 고추장 등 전통 발효 장류를 베이스로 다양한 양념장을 만들어냅니다.

## 발효 장류 베이스

### [[된장]]
- 콩 발효로 만든 구수한 장
- 된장찌개, [[쌈장]], [[나물 (개요)]]

### [[간장 양념]]
- 콩 발효 액체, 짠맛과 감칠맛
- 불고기, 소고기, 조림 양념

### [[고추장 양념]]
- 고춧가루 + 찹쌀 + 메주 발효
- 비빔밥, 떡볶이, [[찌개 (개요)]]

## 쌈·회 소스

### [[쌈장]]
- 된장 + 고추장 + 마늘 + 참기름
- 채소쌈, 고기쌈에 필수

### [[초고추장]]
- 고추장 + 식초 + 설탕
- 회, 회, 비빔국수

### [[겨자 소스]]
- 겨자 + 식초 + 설탕
- 보쌈, 양장피, 만두

## 구이·조림 양념장

### 불고기 양념
- 간장 + 설탕 + 동치미 + 참기름
- 불고기, 삼겹살구이

### 찜·조림 양념
- 간장 + 설탕 + 마늘 + 생강
- 갈비찜, 장조림

## 특징

### 발효의 힘
- **감칠맛**: 발효로 아미노산 생성
- **구수함**: 장기 숙성으로 깊은 맛
- **보존성**: 소금 + 발효로 장기 보관

### 단짠 조합
- **균형**: 간장·된장 + 설탕·물엿
- **조화**: 단짠 맛으로 중독성

### 참기름 마무리
- **고소함**: 참기름으로 풍미 완성
- **향**: 마지막에 넣어 휘발 방지

## 조리 팁

### 양념장 만들기
1. **베이스**: 간장 또는 된장·고추장
2. **단맛**: 설탕, 물엿, 조청, 배즙
3. **향**: 다진 마늘, 생강, 파
4. **고소함**: 참기름, 통깨

### 보관
- **냉장**: 밀폐 용기 2주
- **냉동**: 양념육 형태로 냉동 가능
- **상온**: 발효 장류는 서늘한 곳
