# 쫄면

## 재료 (2인분)
- 쫄면 300g
- 오이 1개 (채 썰기)
- 양배추 150g (채 썰기)
- 당근 50g (채 썰기)
- 상추 3장 (한입 크기로 썰기)
- 삶은 계란 2개 (반으로 자르기)
- 깨소금 1T

**양념장**
- 고춧가루 3T
- 고추장 2T
- 간장 2T
- 설탕 3T
- 식초 3T
- 다진 마늘 1T
- 생강즙 1t
- 참기름 1T
- 통깨 1T
- 물 5T

## 조리법

1. **양념장 만들기**: 볼에 양념장 재료를 모두 넣고 설탕이 완전히 녹을 때까지 잘 섞음. 냉장고에 30분간 숙성하면 맛이 더 깊어짐.

2. **쫄면 삶기**: 끓는 물에 쫄면을 넣고 3-4분간 삶음. 쫄면이 투명해지고 쫄깃해지면 체에 건져 찬물에 3번 헹굼. 얼음물에 1분간 담가 식감 살림.

3. **채소 준비**: 오이, 양배추, 당근 채는 찬물에 10분간 담가 아삭함 살림. 물기를 완전히 제거.

4. **비빔**: 큰 볼에 쫄면, 채소, 양념장을 넣고 고루 비빔. 장갑을 끼고 손으로 주물러 섞으면 양념이 골고루 배어듦.

5. **마무리**: 접시에 담고 삶은 계란, 깨소금을 올려 완성.

## 조리 팁

**쫄면 식감**: 찬물에 여러 번 헹구고 얼음물에 담가야 쫄깃함이 살아남. 헹굴 때 손으로 주물러 전분을 빼면 더욱 탱탱함.

**매콤달콤 밸런스**: 기본 비율은 고추장:설탕:식초 = 2:3:3. 더 달게는 설탕 4T, 더 시게는 식초 4T로 조절.

**양념장 농도**: 물 5T가 기본이나, 더 진하게 먹고 싶으면 3T로 줄임. 묽게는 7T까지 추가 가능.

**채소 아삭함**: 채소는 먹기 직전에 물기를 제거해야 양념이 물러지지 않음. 키친타월로 꼭 짜거나 샐러드 스피너 사용.

**여름철 시원하게**: 쫄면과 채소를 냉장고에 30분간 차게 식힌 후 비비면 시원함. 얼음 조각을 몇 개 올려도 좋음.

**고명 추가**: 김밥용 햄, 어묵, 맛살을 볶아 채 썰어 올리면 단백질 보충. 김 가루나 쌈무를 곁들여도 맛있음.
