# 한식 (Korean Cuisine)

한식은 발효와 단짠 조합, 다양한 반찬 문화가 특징입니다. 쌀밥 중심의 주식과 국·찌개, 반찬으로 구성된 상차림이 기본입니다.

- [[닭볶음탕]] - 감자·당근과 함께 조린 닭

### [[찌개 (개요)|찌개·국]]

## 한식의 특징

### 발효 문화
- **장류**: 된장, 간장, 고추장
- **김치류**: 유산균 발효
- **젓갈**: 생선·새우 발효
- **막걸리**: 쌀 발효주

### 맛의 조화
- **단짠**: 간장·설탕 조합
- **매콤달콤**: 고추장·설탕
- **구수한맛**: 된장·볶은 곡물
- **감칠맛**: 발효·육수

### 상차림
- **밥**: 주식
- **국·찌개**: 국물 요리
- **반찬**: 3-12가지
- **김치**: 필수

### 조리 기법
- **조림**: 간장 양념 오래 조리
- **무침**: 데쳐서 참기름 양념
- **볶기**: 강불 빠른 조리
- **찌기**: 수증기 조리

- 고추장 베이스: 고추장 2 : 설탕 1
- 마지막에 참기름

## 💡 조리 팁 (한식 공통)

### 기본 양념
- **간장 양념**: 간장 + 설탕 + 다진 마늘 + 참기름
- **고추장 양념**: 고추장 + 고춧가루 + 간장 + 설탕
- **된장 양념**: 된장 + 다진 마늘 + 참기름

### 육수
- **멸치 육수**: 멸치 + 다시마 (20분)
- **사골 육수**: 사골 (3시간 이상)
- **채소 육수**: 무 + 양파 + 대파

### 발효
- **김치**: 상온 1-2일 → 냉장
- **된장/고추장**: 장기 숙성
- **젓갈**: 염도 20% 이상
