# 나물 (개요)

> 채소를 데치거나 볶아 양념에 무친 반찬. 조리법은 단순하지만 데치는 시간과 물기 제거 정도가 결과를 거의 다 결정한다.

## 시작하기

나물은 재료가 바뀌어도 순서가 같다. 가열 → 냉각 → 물기 제거 → 무치기. 가열 시간이 짧은 것부터 익히면 감이 빨리 잡힌다.

1. [[시금치나물]] — 데치고 찬물에 식혀 짜는 기본 동작 전부
2. [[숙주나물]] — 30초만 가열하는 극단적으로 짧은 예
3. [[콩나물무침]] — 콩 비린내를 다루는 가열법
4. [[무생채]] · [[오이무침]] — 가열 없이 소금 절임만으로 만드는 생채
5. [[고사리나물]] · [[도라지무침]] — 불리기·쓴맛 빼기가 붙는 응용

**물기를 짜는 정도가 양념 농도를 결정한다.** 데친 채소에 물이 남으면 양념이 희석되고 시간이 지나면서 바닥에 물이 고인다. 반대로 지나치게 짜면 세포가 뭉개져 식감이 사라진다. 손으로 두세 번 가볍게 쥐어짜는 정도가 기준이다.

참기름은 마지막에 넣는다. 참기름의 향 성분은 휘발성이라 열이나 긴 교반에 날아가고, 먼저 넣으면 채소 표면을 기름막으로 덮어 간장·소금이 스며들지 못한다.

데치는 물에 소금을 넣으면 색이 선명해지는 것은 사실이지만, 이유는 흔히 말하는 "색소 고정"보다 **가열 시간이 짧아지고 세포막 손상이 줄어드는 쪽**에 가깝다. 녹색이 유지되는 결정적 요인은 데친 직후의 급속 냉각이다.

가열 시간은 재료의 섬유 상태에 따라 갈린다. 자세한 원리는 [[데치기]] 참조.

| 구분 | 대표 재료 | 대략적 가열 | 판단 기준 |
|---|---|---|---|
| 잎채소 | 시금치, 미나리, 깻잎 | 30초~1분 | 색이 짙어지고 숨이 죽는 순간 |
| 싹채소 | 숙주, 콩나물 | 30초~3분 | 씹었을 때 아삭함이 남는 정도 |
| 뿌리·건나물 | 도라지, 고사리 | 3~5분 (불린 뒤) | 손톱으로 눌러 들어가는 정도 |

양념은 크게 셋이다. 어느 것을 쓰느냐에 따라 같은 채소도 다른 반찬이 된다.

| 양념 | 배합 (1인분 기준) | 어울리는 재료 |
|---|---|---|
| 간장 양념 | 국간장 1t + 참기름 1T + 다진 마늘 1t + 깨소금 | 시금치, 숙주, 가지 |
| 고춧가루 양념 | 고춧가루 1T + 간장 1t + 설탕 1t + 식초 1T + 참기름 | 무, 오이, 도라지 |
| 된장 양념 | 된장 1t + 참기름 1T + 다진 마늘 + 설탕 약간 | 취나물, 시래기, 열무 |

## 전체 목록

**데쳐 무치는 나물**

- [[시금치나물]] — 30초~1분 데쳐 국간장·참기름에 무침
- [[숙주나물]] — 짧게 데쳐 아삭함을 남기는 나물
- [[콩나물무침]] — 비린내를 잡는 가열이 관건
- [[도라지무침]] — 소금에 주물러 쓴맛을 뺀 뒤 새콤달콤하게
- [[파래무침]] — 헹궈 모래를 빼고 무치는 해조류

**볶거나 쪄서 만드는 나물**

- [[가지나물]] — 삶지 않고 쪄서 물을 덜 먹인다

- [[고사리나물]] — 불려 삶고 물을 부어 뜸 들이듯 볶는다

**가열 없이 무치는 생채**

- [[무생채]] — 무를 잠깐 절여 고춧가루 양념에
- [[오이무침]] — 절여 물기를 뺀 뒤 새콤달콤하게

**조림·볶음 밑반찬**

- [[감자조림]] — 볶아 겉을 굳힌 뒤 조림장에 졸임

- [[장조림]] — 삶아 찢은 소고기를 간장에 졸임
- [[멸치볶음]] — 불을 끄고 양념에 버무린다
- [[어묵볶음]] — 데쳐 기름기를 뺀 뒤 볶음
- [[마늘종볶음]] — 센 불에 짧게 볶아 아삭함 유지
- [[마늘종장아찌]] — 절임액에 담가 1주 숙성
