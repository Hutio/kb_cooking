# 찜닭

> 닭을 간장 양념에 졸이고 마지막에 당면을 넣어 국물을 흡수시키는 안동식 요리.

## 재료

- 닭 1마리 (1.2kg, 한입 크기 토막)
- 감자 2개 (200g, 큼직하게 썰기)
- 당근 1개 (100g, 어슷 썰기)
- 양파 1개 (150g, 큼직하게 썰기)
- 당면 100g (찬물에 30분 불리기)
- 대파 1대 (5cm 길이로 썰기)
- 떡볶이떡 150g
- 청양고추 3개 (어슷 썰기)

### 양념

- 간장 8T
- 물엿 5T
- 설탕 3T
- 맛술 3T
- 다진 마늘 2T
- 생강즙 1T
- 후추 1t
- 물 2컵

## 만드는 법

1. **닭 손질**: 닭을 찬물에 담가 핏물(미오글로빈 용액) 제거 후 끓는 물에 1분간 데쳐 잡내 제거. 찬물에 헹군 후 물기 제거.

2. **양념장 만들기**: 볼에 양념장 재료를 모두 넣고 잘 섞어 설탕이 완전히 녹을 때까지 저음.

3. **1차 조림**: 깊은 냄비에 닭, 감자, 당근을 넣고 양념장을 부어 센 불에서 끓임. 끓어오르면 중불로 줄여 뚜껑을 덮고 20분간 조림.

4. **재료 추가**: 양파, 당면, 떡을 넣고 10분간 더 조림. 중간에 국물을 끼얹어가며 골고루 익힘.

5. **마무리**: 대파, 청양고추를 넣고 3분간 졸여 국물이 자작해지면 완성. 참기름 1T를 뿌려 윤기 더함.

## 핵심 포인트

**간장 선택**: 진간장과 양조간장을 4:4 비율로 섞으면 색과 맛의 균형이 좋음. 진간장만 쓰면 색이 너무 진해질 수 있음.

**당면 식감**: 당면을 너무 오래 익히면 퍼지므로 마지막 10분에만 넣음. 불린 당면을 가위로 한 번 잘라주면 먹기 편함.

**윤기 내기**: 조리 마지막에 물엿 1T를 추가로 넣고 센 불에서 30초간 빠르게 저으면 윤기가 더 남. 참기름도 필수.

**감자 부서짐 방지**: 감자는 전분이 많은 수미감자보다 단단한 대지감자 사용. 너무 작게 자르지 않고 큼직하게 썰기.

**매운맛 제거**: 아이들용으로 만들 때는 청양고추 대신 파프리카 반 개를 넣어 색감 유지. 간장 양을 7T로 줄이고 물엿을 6T로 늘림.

**실패 구출법**: 닭이 퍽퍽하면 물 1컵 추가 후 약불에서 뚜껑 덮고 15분 더 조림. 양념이 너무 짜면 물 반 컵 + 물엿 2T 추가. 당면이 퍼졌으면 새 당면을 불려 추가 투입.

**대체재**: 닭 → 닭다리살(뼈 없는 것, 조리시간 5분 단축), 당면 → 쫄면 사리(식감이 더 쫄깃), 물엿 → 꿀이나 올리고당(비율 동일)

**보관법**: 냉장 3일, 냉동 2주. 당면은 냉장 시 불어서 식감이 떨어지므로 당면 없이 보관 후 재가열 때 새 당면 추가 권장.

**재가열**: 냄비에 물 3T 넣고 중불에서 뚜껑 덮어 8분. 전자레인지 시 랩 씌워 3분.

## 응용 변형

- **2인분 조절**: 닭다리 4개(600g), 양념장 절반, 감자·당근 각 1개. 조리시간 동일
- **매운 찜닭**: 고춧가루 2T + 고추장 1T 추가. 설탕 1T 더 넣어 매콤달콤 밸런스
- **해물찜닭**: 닭과 함께 오징어 1마리, 새우 10마리 추가. 해물은 마지막 5분에 투입
- **치즈찜닭**: 완성 후 모짜렐라 치즈를 올리고 뚜껑 덮어 2분. 치즈가 녹으면 완성. 단체 모임 인기 메뉴
- **찜닭 볶음밥**: 남은 찜닭을 잘게 잘라 밥과 볶으면 간장 볶음밥. 계란 프라이 올리기

## 유래

찜닭은 경상북도 안동 지역의 향토 음식으로, 원래 이름은 "안동찜닭"이다. 안동 구시장 닭골목에서 1980년대부터 판매되기 시작했으며, 통닭집들이 경쟁하면서 간장 양념에 당면과 채소를 넣는 현재의 형태가 완성되었다. 2000년대 초반 전국적으로 프랜차이즈가 퍼지면서 국민 요리로 자리잡았다. 본래 안동 찜닭은 현재보다 더 짜고 매운 것이 특징이었다.
