# 치즈 피자

## 주요 재료

**피자 도우 (2판, 25cm 기준)**
- 강력분 300g
- 미지근한 물 180ml
- 드라이 이스트 5g
- 설탕 1t
- 소금 1t
- 올리브유 2T

**토마토 소스**
- 토마토 페이스트 4T
- 다진 마늘 1t
- 올리브유 1T
- 오레가노 1t
- 바질 1t
- 소금 1/4t
- 설탕 1/2t
- 물 2T

**치즈 토핑**
- 모짜렐라 치즈 300g, 갈아서
- 체다 치즈 100g, 갈아서
- 파마산 치즈 50g, 갈아서
- 고르곤졸라 50g (선택, 블루치즈 풍미)
- 올리브유 1T
- 오레가노 1t (마무리용)

## 조리법

1. **도우 만들기 (15분 + 1시간 발효)**
   - 볼에 미지근한 물 180ml, 설탕 1t, 드라이 이스트 5g 넣고 섞기
   - 5분간 기다려 이스트 활성화 (거품 생김)
   - 강력분 300g과 소금 1t를 체에 쳐서 넣기
   - 올리브유 2T 추가하고 반죽 시작
   - 도마에 꺼내 10분간 치댁 (매끄럽고 탄력 생기게)
   - 볼에 담고 젖은 면보로 덮어 따뜻한 곳에서 1시간 발효

2. **토마토 소스 만들기 (5분)**
   - 작은 볼에 토마토 페이스트 4T 담기
   - 다진 마늘, 올리브유, 오레가노, 바질, 소금, 설탕 넣기
   - 물 2T 추가해 잘 섞어 부드럽게 만들기
   - 5분간 그대로 두어 향이 배게 하기

3. **도우 성형 (5분)**
   - 발효된 반죽을 도마에 꺼내 가스 빼기
   - 2등분으로 나누기
   - 각 반죽을 25cm 원형으로 밀기 (중앙은 얇게, 가장자리는 두껍게)
   - 유산지를 깐 베이킹 시트에 올리기
   - 포크로 중앙 부분만 여러 번 찌르기 (부풀음 방지)

4. **토핑 올리기**
   - 도우에 토마토 소스를 고르게 바르기 (가장자리 1cm는 남기기)
   - 모짜렐라 치즈의 절반을 먼저 뿌리기
   - 체다 치즈 전체를 고르게 뿌리기
   - 남은 모짜렐라 치즈 뿌리기
   - 고르곤졸라를 작은 조각으로 떼어 군데군데 올리기 (선택)
   - 파마산 치즈 갈아 뿌리기
   - 올리브유를 표면에 살짝 뿌리기

5. **굽기 (12-15분)**
   - 오븐을 250도로 예열 (최소 15분 전)
   - 피자를 오븐 중간 선반에 넣기
   - 12-15분간 굽기
   - 치즈가 녹아 황금빛 갈색 반점(브라우닝)이 생기면 완료
   - 가장자리가 노릇하고 바삭해야 함
   - 오븐에서 꺼내 2-3분 식힌 후 자르기

6. **마무리**
   - 오레가노 1t를 표면에 뿌리기
   - 신선한 바질 잎 5-6장 올리기 (선택)
   - 8조각으로 자르기

## 조리 팁

1. **치즈 블렌딩**: 여러 종류의 치즈를 섞으면 맛의 깊이가 살아납니다. 모짜렐라는 늘어남, 체다는 풍미, 파마산은 짠맛, 고르곤졸라는 강렬함을 더합니다.

2. **저수분 모짜렐라 선택**: 신선한 모짜렐라(fresh mozzarella)는 물이 많아 피자가 눅눅해집니다. 저수분 모짜렐라(low-moisture mozzarella)를 쓰세요.

3. **치즈 갈기**: 미리 간 치즈는 첨가물(anti-caking agent)이 있어 잘 안 녹습니다. 블록 치즈를 직접 갈아 쓰면 훨씬 부드럽게 녹고 맛있습니다.

4. **소스 양 조절**: 소스를 너무 많이 바르면 도우가 눅눅해집니다. 얇게 펴 바르되 도우가 비치지 않을 정도만 바르세요.

5. **가장자리 처리**: 토마토 소스와 치즈를 가장자리 1cm는 비워두세요. 이 부분이 부풀며 황금빛 코르니체(crust)가 됩니다.

6. **오븐 예열의 중요성**: 오븐이 충분히 뜨겁지 않으면 도우가 바삭해지지 않고 질깁니다. 250도에서 최소 15분 예열하세요.

7. **피자 스톤 또는 강판**: 피자 스톤이나 뒤집은 베이킹 강판을 오븐에 함께 예열하면 바닥이 더 바삭하게 구워집니다. 피자를 직접 돌 위에 슬라이드해 굽는 것이 이상적입니다.
