# 양식 (European Cuisine)

양식은 프랑스, 이탈리아를 중심으로 한 서양 요리로, 버터·크림의 고소함과 허브 향이 특징입니다. 5대 모체 소스를 기반으로 체계적인 조리법이 발달했습니다.

## 카테고리별 양식

### 파스타
- [[까르보나라]] - 계란 + 베이컨 크림
- [[봉골레]] - 바지락 파스타
- [[알리오 올리오]] - 마늘 오일 파스타
- [[페스토 파스타]] - 바질 소스
- [[토마토 파스타]] - 미트소스 파스타

### [[피자]]
- [[마르게리타 피자]] - 토마토 + 모짜렐라 + 바질
- 페퍼로니 피자
- 하와이안 피자

### [[스테이크]]
- [[스테이크]] - 마블링 풍부
- 안심 스테이크 - 부드러움
- [[스테이크]] - 후추 크러스트

### [[수프|수프·스튜]]
- [[수프]] - 이탈리아 야채 수프
- 클램 차우더 - 조개 크림 수프
- 비프 스튜 - 소고기 스튜

### 기타 메인
- [[리조또]] - 크림 쌀 요리
- [[그라탱]] - 베샤멜 + 치즈 오븐 구이
- 돈까스 - 일본식 양식
- 동그랑땡 - 다진 고기 패티

## 양식 특징

### 조리 기법
- **굽기**: 스테이크, 로스트
- **삶기**: 파스타
- **오븐 굽기**: 그라탱, 피자
- **소스 만들기**: 루, 유화, 환원

### 맛의 특징
- **버터·크림**: 고소하고 부드러움
- **허브**: 바질, 타임, 로즈마리
- **치즈**: 감칠맛, 풍부함
- **와인**: 산미와 복합미

### 필수 재료
- 버터, 크림, 치즈
- 올리브유
- 바질, 타임, 파슬리
- 토마토, 마늘
- 파스타, 밀가루

## 소스

### 5대 모체 소스
1. **베샤멜** - 우유 베이스
2. **벨루테** - 화이트 스톡
3. **에스파뇰** - 브라운 스톡
4. **토마토 소스** - 토마토
5. **홀랜다이즈** - 계란 유화

### 기타 소스
- 페스토 - 바질 소스
- 알프레도 소스 - 크림 치즈
- 마요네즈, 타르타르 소스

## 지역별 요리

### 이탈리아
- 파스타 (개요), [[피자]], [[리조또]]
- 바질, 토마토, 올리브유

### 프랑스
- 5대 모체 소스
- 베샤멜, 부케 가르니
- 정교한 기법

### 스페인
- 파에야, 타파스
- 파프리카, 사프란

### 독일
- 소시지, 자우어크라우트
- 맥주 요리

## 조리 팁

### 파스타 삶기
1. 물 충분히 + 소금
2. 알단테 (7-9분)
3. 면수 1컵 남기기
4. 소스와 버무리기

### 스테이크 굽기
1. 실온 30분
2. 팬 충분히 예열
3. 한 번만 뒤집기
4. 5분 휴지

### 소스 만들기
- 루(Roux): 버터 + 밀가루
- 액체 조금씩 추가
- 계속 저으며 끓이기
