# 기타 재료 (개요)

> 육류·채소·해산물·조미료 어디에도 안 들어가지만 없으면 요리가 안 되는 것들. 대부분 **단백질 아니면 전분**이다.

## 시작하기

**단백질이 굳는 온도를 알면 계란·두부가 쉬워진다**

- [[계란]] 흰자 62~65°C, 노른자 65~70°C에서 굳는다. 이 차이가 반숙·수란·온천란을 만든다.
- [[두부]]는 이미 굳혀 놓은 콩단백이다. 다시 가열해도 더 단단해지지 않지만, 얼리면 얼음 결정이 조직을 뚫어 스펀지 구조가 된다 — 언두부는 변질이 아니라 **다른 식재료**다.

**전분과 글루텐이 식감을 만든다**

- [[밀가루]]는 단백질(글루텐) 함량으로 나뉜다. 강력분(빵) > 중력분(면·부침) > 박력분(과자). 글루텐이 많을수록 쫄깃하고 적을수록 바삭하다.
- [[전분]]은 글루텐이 없다. 튀김옷에 섞으면 바삭해지고, 물에 풀어 넣으면 걸쭉해진다. 종류마다 호화 온도와 투명도가 달라 감자전분은 중식 걸쭉이, 옥수수전분은 튀김옷 쪽이 맞는다.
- 튀김이 눅눅해지는 것도, 소스가 식으면 되직해지는 것도 전분의 성질 하나로 설명된다.

**보관 성격이 극단적으로 갈린다**

| 재료 | 수명 |
|---|---|
| [[두부]] | 개봉 후 2~3일. 매일 물을 갈아야 한다 |
| [[계란]] | 냉장 3~5주 (씻지 않은 상태 기준) |
| [[버터]] | 냉장 2~3주 / 냉동 6개월. 냄새를 강하게 흡착하므로 밀봉 필수 |
| [[밀가루]] | 개봉 후 3~6개월. 벌레와 습기가 적 |
| [[전분]] | 실온 1~2년 |
| [[꿀]] | 사실상 무기한 |

**꿀 주의**: 만 1세 미만 영아에게는 절대 먹이지 않는다. 보툴리누스균 아포가 성인에게는 무해하지만 영아 장에서는 증식한다.
