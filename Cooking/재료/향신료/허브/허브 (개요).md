# 허브 (개요)

> 허브를 외울 필요는 없다. **연질이냐 경질이냐** 하나만 구분하면 보관법도, 넣는 시점도, 생/건조 선택도 따라 나온다.

## 시작하기

**하나의 축으로 전부 정리된다**

| | 연질 허브 | 경질 허브 |
|---|---|---|
| 대상 | [[바질]] [[파슬리]] [[고수]] [[딜]] [[민트]] | [[로즈마리]] [[타임]] [[세이지]] [[오레가노]] |
| 생김새 | 잎이 부드럽고 줄기가 초록 | 목질 줄기, 잎이 작고 단단 |
| 향 성분 | 저비점 — 열에 쉽게 날아감 | 고비점 — 열에 견딤 |
| 넣는 시점 | **마지막에, 또는 생으로** | **조리 초반부터 우려낸다** |
| 건조하면 | 향이 죽는다 (환산 불가) | 향이 살아남는다 (건조가 표준) |
| 단기 보관 | 줄기 자르고 물컵에 꽂아 봉지 씌워 냉장 | 축인 키친타월에 감싸 밀폐 냉장 |

**생 ↔ 건조 환산은 3 : 1**. 생 1큰술 ≈ 건조 1작은술. 단 연질 허브에는 이 환산이 성립하지 않는다 — 말린 바질은 생바질의 대용품이 아니라 다른 재료다.

**보관 수명 (단기)**

물컵법 — [[파슬리]] 10~14일 · [[고수]] 7~10일 · [[민트]] 7~10일 · [[딜]] 5~7일.
[[바질]]만 예외로 **냉장 금지**, 실온 18~22°C 5~7일 (10°C 이하에서 잎이 검게 변하는 냉해).
밀폐 냉장 — [[로즈마리]] 2~3주 · [[타임]] 2주 · [[세이지]]·[[오레가노]] 1~2주.

**장기 보관**
- 얼음틀에 다져 넣고 올리브유·버터를 부어 냉동 — 6개월. 연질 허브의 최선책.
- 다발로 묶어 그늘 건조 — 6~12개월. 경질 허브용.
- 소금 1:1 절임 6개월, 허브 버터 3개월, 식초 침지 2~3개월.
- **주의**: 생 허브를 기름에 담가 실온에 두면 보툴리누스 위험이 있다. 반드시 냉장 0~4°C, 4일 이내.

**향 화합물 지도** — 왜 어떤 허브끼리 잘 어울리는지가 여기서 설명된다.

[[타임]]과 [[오레가노]]는 티몰·카바크롤을 공유해 서로 대체가 가능하다. [[로즈마리]]와 [[세이지]]는 캄퍼를 공유한다. [[딜]]과 [[민트]]의 카르본은 거울상 이성질체 관계라 화학적으로는 같은 골격인데 향이 전혀 다르다. [[고수]]를 비누 맛으로 느끼는 것은 취향이 아니라 OR6A2 유전자형 문제다.

**한국 마트 기준**
- 생으로 쉽게: [[파슬리]] [[고수]] [[바질]] [[민트]]
- 건조가 사실상 표준: [[오레가노]] [[타임]] [[세이지]]
- 구하기 까다로움: [[딜]]
