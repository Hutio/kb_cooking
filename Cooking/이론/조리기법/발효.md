# 발효 (Fermentation)

## 개요
발효는 미생물(효모, 박테리아, 곰팡이)이 음식의 당분을 분해하여 새로운 맛, 향, 영양소를 만들어내는 과정입니다. 인류가 수천 년간 사용해온 전통 보존법이자 맛을 극대화하는 기술로, 한국 음식의 핵심입니다.

## 발효의 원리

### 미생물 종류
- **유산균**: 김치, 요거트, 치즈 (산미)
- **효모**: 빵, 술, 간장 (알코올, 향)
- **곰팡이**: 된장, 고추장, 치즈 (감칠맛)
- **초산균**: 식초 (신맛)

### 발효 vs 부패
- **발효**: 유익한 미생물이 음식을 변화시켜 맛있고 건강하게
- **부패**: 유해 미생물이 음식을 썩혀 먹을 수 없게

발효 조건(온도, 염도, 산도)을 적절히 조절하면 유익한 미생물만 번식합니다.

## 한국의 대표 발효 음식

### 김치류
- [[배추김치]] - 유산균 발효, 신맛과 깊은 맛
- 깍두기 - 무 + 고춧가루 발효
- 총각김치 - 알타리무 발효
- 백김치 - 고춧가루 없이 발효
- 동치미 - 무 물김치, 청량한 맛

### 장류 (메주 발효)
- 된장 - 콩 발효, 구수한 감칠맛
- 간장 - 콩 발효 액체, 짠맛
- 고추장 - 콩 + 고춧가루 + 찹쌀 발효, 매콤달콤
- 청국장찌개 - 콩 단기 발효, 강한 냄새와 깊은 맛

### 절임류
- 젓갈 - 새우젓, 멸치젓, 명란젓
- 마늘종장아찌 - 채소를 간장/된장에 절임

### 음료
- 발효 - 쌀 효모 발효, 알코올 6-8%
- 발효 - 쌀 엿기름 발효, 단맛
- 생강차 - 생강·곶감 발효

## 발효의 단계

### 1. 준비
- 재료 씻고 손질
- 소금에 절이기 (김치)
- 메주 쑤기 (장류)

### 2. 1차 발효 (초기)
- 미생물 번식 시작
- 온도 18-22°C
- 거품 생기고 부글부글
- 신맛 약함

### 3. 2차 발효 (숙성)
- 온도 낮춤 (10-15°C)
- 천천히 발효
- 맛이 깊어짐
- 유산균 증가

### 4. 완숙
- 신맛 강해짐
- 깊은 감칠맛
- 김치는 물러지기 시작

## 발효 성공의 핵심

### 온도 관리
- **18-22°C**: 빠른 발효 (여름, 김치 익히기)
- **10-15°C**: 천천히 발효 (겨울, 장기 보관)
- **5°C 이하**: 발효 멈춤 (냉장 보관)
- **30°C 이상**: 부패 위험

### 염도 조절
- **3-5%**: 김치 적정 염도 (너무 짜지 않고 발효 적당)
- **10-15%**: 장아찌 (장기 보관)
- **20% 이상**: 젓갈 (부패 방지)

### 산소 차단
- 김치는 공기 닿으면 곰팡이
- 용기 가득 채우기
- 국물에 잠기게

### 청결
- 모든 도구 깨끗이 씻기
- 손 깨끗이 씻기
- 유해 미생물 방지

## 발효 음식의 효능

### 건강
- **유산균**: 장 건강, 면역력 강화
- **소화 효소**: 음식 소화 돕기
- **비타민 B**: 발효 과정에서 생성
- **항산화**: 폴리페놀 증가

### 맛
- **감칠맛**: 아미노산 생성
- **신맛**: 유산 생성
- **향**: 에스테르, 알코올 생성
- **복합미**: 시간에 따라 맛 변화

### 보존
- 발효 음식은 부패 방지
- 냉장 없이도 오래 보관 (전통 시대)

## 발효 실패 원인

### 부패
- 온도 너무 높음 (30°C 이상)
- 염도 너무 낮음
- 청결 불량
- 공기 접촉 많음

### 과발효
- 너무 오래 상온 보관
- 물러지고 무르고 시큼함
- 냉장 이동 타이밍 놓침

### 미발효
- 온도 너무 낮음
- 염도 너무 높음
- 재료 불량

## 집에서 쉬운 발효

### 초보용
- **깍두기**: 무 + 고춧가루 + 소금, 2-3일
- **오이소박이**: 오이 + 양념, 1-2일
- **겉절이**: 배추 + 양념, 당일

### 중급
- **배추김치**: 배추 절이기 + 양념 + 1-2주
- **물김치**: 무 + 국물 + 3-4일

### 고급
- **된장**: 메주 + 소금물 + 6개월-1년
- **고추장**: 메주가루 + 고춧가루 + 찹쌀 + 3개월

## 발효 보관법
- **냉장**: 5°C 이하, 발효 멈춤, 장기 보관
- **김치냉장고**: 0-1°C, 최적 온도
- **밀폐**: 공기 차단, 곰팡이 방지
- **국물 잠기게**: 재료가 국물에 잠겨야 부패 방지

## 세계의 발효 음식
- **일본**: 미소(된장), 낫토(청국장 비슷), 쓰케모노(장아찌)
- **유럽**: 치즈, 요거트, 사우어크라우트(양배추절임)
- **동남아**: 피시소스(젓갈), 템페(콩발효)
- **중국**: 두반장(콩발효), 피클류
