# 찌기 (Steaming)

> 끓는 물에서 올라온 수증기가 재료 표면에서 응축하며 잠열을 넘겨주는 기법. 재료가 물에 잠기지 않아 수용성 성분이 씻겨 나가지 않고, 형태가 무너지지 않는다.

## 원리

| 방식 | 열전달 | 매질 온도 | 특징 |
|---|---|---|---|
| 상압 찌기 | 응축 잠열 + 대류 | 100°C | 재료 표면에 물방울이 맺히며 열을 준다 |
| 약한 증기 | 응축 + 대류 | 85~95°C | 계란찜·커스터드용. 기포 없이 매끈하다 |
| 압력솥 | 응축 잠열 | 약 121°C(1기압 게이지) | 조리 시간이 1/3까지 줄어든다 |
| 중탕 | 전도(물) | 60~90°C | 정밀 온도 조절. 초콜릿·소스용 |
| 오븐 스팀 | 대류 + 증기 | 설정 온도 | 표면 건조를 늦춘다 |

**증기의 열은 온도가 아니라 응축에서 나온다.** 100°C 수증기 1g이 100°C 물로 응축할 때 약 2.26kJ을 내놓는다. 같은 온도의 공기와는 비교가 안 되는 열량이고, 이 때문에 100°C짜리 오븐보다 100°C 증기가 훨씬 빨리 익힌다.

**물이 팔팔 끓기만 하면 증기 온도는 100°C로 고정된다.** 화력을 더 올려도 증기가 더 뜨거워지지 않는다. 늘어나는 것은 증기의 양뿐이고, 대신 물이 빨리 준다. **필요한 화력은 "증기가 끊기지 않을 만큼"이지 "가장 센 불"이 아니다.**

**찌기가 삶기보다 부드러운 이유는 온도가 아니라 접촉이다.** 둘 다 100°C지만, 삶기는 물이 재료를 씻어내 수용성 비타민·당·향이 국물로 빠져나간다. 찌기는 그 손실이 훨씬 작다. 대신 잡내를 물로 빼내는 효과도 없다.

## 기본 방법

1. **물은 2~3cm.** 재료에 닿으면 삶기가 되고, 너무 적으면 중간에 마른다.
2. **물이 완전히 끓은 뒤 재료를 넣는다.** 찬 상태에서 함께 올리면 재료가 미지근한 습기에 오래 노출돼 색과 식감을 잃는다.
3. **재료를 겹치지 않게 편다.** 증기가 돌 틈이 없으면 아래쪽만 익는다.
4. **뚜껑 안쪽을 면포로 감싼다.** 응축수가 재료에 떨어지면 그 부분이 질척해지고 색이 빠진다.
5. **중간에 뚜껑을 열지 않는다.** 한 번 열면 증기가 다 빠지고 회복에 1~2분이 든다.
6. **물이 부족하면 끓는 물을 보충한다.** 찬물을 부으면 증기가 끊긴다.

**재료별 시간** (상압 100°C, 한 겹으로 폈을 때 기준)

| 재료 | 시간 | 완료 판단 |
|---|---|---|
| 브로콜리·아스파라거스 | 3~5분 | 색이 선명해지고 줄기가 살짝 휨 |
| 당근(1cm 편) | 6~8분 | 꼬치가 저항 없이 들어감 |
| 감자(중간 크기 반쪽) | 15~20분 | 꼬치가 중심까지 들어감 |
| 고구마(통) | 25~40분 | 굵기에 따라 크게 다르다 |
| 새우·조개 | 4~6분 | 새우는 굽고 불투명, 조개는 입이 벌어짐 |
| 흰살생선 필레 | 7~10분 | 살이 켜로 갈라짐. 심부 50~55°C |
| 생선 통째 | 12~18분 | 등뼈 근처 살이 분리됨 |
| 닭가슴살 | 15~20분 | 심부 74°C |
| 수육용 돼지 삼겹·목살 | 40~70분 | 꼬치가 저항 없이 들어감 |
| 만두(생) | 8~12분 | 피가 반투명해짐 |
| 백설기 | 20~25분 | 꼬치에 반죽이 묻어나지 않음 |
| 인절미용 찹쌀 | 25~30분 | 알갱이 심이 없음 |
| 계란찜 | 12~18분(약한 증기) | 흔들면 가운데가 살짝 출렁 |

**약한 증기가 필요한 것도 있다.** 계란찜·커스터드는 100°C 강한 증기에서는 단백질이 급하게 응고해 기포가 생기고 물이 분리된다. 물이 살짝 떨리는 정도(85~90°C)로 낮추고 뚜껑을 살짝 열어 두면 표면이 매끈해진다. **"무조건 센 불"이 통하지 않는 대표 사례다.**

## 변수

| 변수 | 방향 | 결과 |
|---|---|---|
| 화력 | 증기가 끊기지 않는 선 이상은 무의미 | 더 올려도 100°C. 물만 빨리 준다 |
| 재료 배치 | 겹치지 않을수록 | 겹치면 익힘이 불균일 |
| 뚜껑 밀폐 | 셀수록 | 증기 유지에 유리하나 계란찜엔 불리 |
| 압력 | 1기압 게이지 = 121°C | 시간이 1/3~1/2로 준다 |
| 재료 두께 | 두꺼울수록 | 시간은 두께의 제곱에 가깝게 는다 |
| 소금·양념 | 표면에만 작용 | 찌는 동안 속으로 거의 안 들어간다 |
| 재료 초기 온도 | 냉장 상태면 +2~5분 | 냉동은 해동 후 |

## 흔한 실수

| 증상 | 원인 | 대처 |
|---|---|---|
| 아래쪽만 익고 위는 설익음 | 재료를 겹쳐 담음 | 한 겹으로 펴거나 2단으로 나눈다 |
| 떡·만두 표면이 질척하다 | 뚜껑 응축수가 떨어짐 | 뚜껑을 면포로 감싼다 |
| 냄비가 타는 냄새 | 물이 다 증발 | 끓는 물을 보충. 긴 조리는 물을 넉넉히 |
| 계란찜에 구멍이 숭숭 | 증기가 너무 강함 | 85~90°C로 낮추고 뚜껑을 살짝 연다 |
| 생선살이 부서진다 | 과조리 | 심부 50~55°C에서 꺼낸다 |
| 채소 색이 누렇다 | 시간 초과 | 3~5분 넘기지 않는다 |
| 시간이 예상보다 오래 걸린다 | 뚜껑을 자주 열었다 | 한 번 열 때마다 1~2분 손해 |

**"약불로 오래 찌면 질겨진다"는 부정확한 설명이다.** 증기 온도는 어차피 100°C로 같다. 질겨지는 진짜 원인은 **총 가열 시간이 길어진 것**이다. 약불에서는 증기량이 부족해 목표 온도에 도달하기까지 시간이 늘어나고, 그만큼 단백질이 오래 수축한다.

## 적용 요리

| 요리 | 증기 세기 | 시간 | 핵심 |
|---|---|---|---|
| 계란찜 | 약함(85~90°C) | 12~18분 | 체에 한 번 거르면 더 매끈하다 |
| 해물찜 | 강함 | 재료별로 시차 투입 | 조개·새우는 마지막 5분 |
| 찜닭 | 강함 → 조림으로 전환 | 30~40분 | 찌고 나서 국물을 졸인다 |
| 갈비찜 | 강함 또는 압력 | 상압 1.5~2시간 / 압력 30~40분 | 콜라겐이 젤라틴이 되는 데 시간이 필요하다 |
| 백설기·절편 | 강함 | 20~25분 | 김이 오른 뒤 넣는다 |
| 만두 | 강함 | 8~12분 | 바닥에 면포나 유산지 |
| 생선찜 | 강함, 짧게 | 8~15분 | 대파·생강을 밑에 깔아 향을 올린다 |
| 수육 | 강함 | 40~70분 | 삶기보다 지방과 향이 덜 빠진다 |
