# 조림 (Braising / Simmering)

> 적은 양의 양념 국물에서 오래 익히며 국물을 졸이는 기법. 두 가지가 동시에 일어난다 — **재료는 물러지고, 국물은 농축된다.** 조림의 기술은 이 두 시계를 맞추는 데 있다.

## 원리

| 국면 | 온도 | 매질 | 일어나는 일 |
|---|---|---|---|
| 초기 볶기(선택) | 180~220°C | 기름 | 표면 갈변으로 풍미의 바탕을 만든다 |
| 끓임 | 100°C | 양념 국물 | 재료 내부 온도가 올라간다 |
| 시머 | 85~95°C | 양념 국물 | 콜라겐이 젤라틴으로 바뀐다 |
| 졸임 | 100~110°C로 상승 | 농축된 국물 | 당·염 농도가 올라 끓는점이 오른다 |
| 마무리 | 110°C 이상 국소 | 거의 없는 국물 | 캐러멜화·탄화 위험 구간 |

**고기가 부드러워지는 것은 열이 아니라 시간이다.** 근섬유 단백질은 60~68°C에서 이미 수축을 끝내고 수분을 밀어낸다. 이 시점의 고기는 오히려 뻣뻣하다. 그다음 **결합조직의 콜라겐이 물과 함께 68°C 이상에서 서서히 젤라틴으로 바뀌는데, 이 전환에는 시간이 필요하다.** 갈비찜에 1.5~2시간이 드는 이유이고, 온도를 더 올려도 시간을 줄이지 못하는 이유다(압력솥은 예외다 — 121°C에서 반응 속도 자체가 빨라진다).

**양념은 속까지 배지 않는다.** 소금과 설탕은 확산으로 어느 정도 들어가지만, 고춧가루·간장의 향 성분과 색소 대부분은 표면 수 mm에 머문다. **조림에서 "맛이 뱄다"고 느끼는 것은 재료의 물이 빠져나간 자리에 농축된 국물이 들어찬 결과**다. 칼집을 넣고 무를 도톰하게 써는 것이 효과가 있는 이유가 여기 있다.

**국물이 줄면 온도가 올라간다.** 물이 많을 때는 100°C에 묶여 있지만, 국물이 자작해지고 당·염 농도가 올라가면 끓는점이 오르고 바닥은 국소적으로 훨씬 뜨거워진다. **조림이 타는 사고는 거의 전부 마지막 5분에 일어난다.**

## 기본 방법

1. **필요하면 먼저 겉을 지진다.** 고기·두부·생선은 표면 갈변이 국물의 깊이를 바꾼다.
2. **양념 국물을 먼저 끓인다.** 특히 생선은 끓는 국물에 넣어야 표면이 빨리 응고해 부서지지 않고 비린내가 덜하다.
3. **재료가 겨우 잠길 만큼만 붓는다.** 많으면 졸이는 데 시간이 걸려 재료가 먼저 물러진다.
4. **끓으면 중약불로 낮추고 뚜껑을 덮는다.** 초반은 익히는 구간이다.
5. **마지막 1/3 구간에서 뚜껑을 열고 졸인다.** 국물이 처음의 1/3로 줄면 마무리다.
6. **참기름·깨는 불을 끈 뒤에.**

**당과 소금의 투입 순서** — 설탕을 먼저, 소금·간장을 나중에 넣으라는 지시가 널리 쓰인다. 설명으로 붙는 "자당 분자가 커서 늦게 들어가므로"는 근거가 약하다. 실제로 확인되는 것은 **소금이 먼저 들어가면 삼투로 재료의 물이 빠져 조직이 단단해지고 이후 다른 성분의 흡수가 느려진다**는 쪽이다. 순서를 지키는 편이 무난하되, 대단한 차이를 기대할 일은 아니다.

**재료별 기준** (재료가 겨우 잠기는 국물 기준)

| 재료 | 불 세기 | 시간 | 완료 판단 |
|---|---|---|---|
| 갈비찜(소갈비) | 시머 85~95°C | 1.5~2시간 (압력 30~40분) | 뼈에서 살이 밀려남 |
| 장조림(사태·홍두깨) | 시머 | 1~1.5시간 | 결대로 손으로 찢어짐 |
| 닭볶음탕 | 중불 → 중약불 | 30~40분 | 감자에 꼬치가 들어감 |
| 돼지고기 조림(수육형) | 시머 | 50~80분 | 꼬치가 저항 없이 통과 |
| 고등어·갈치조림 | 중약불 | 15~20분 | 살이 켜로 갈라짐 |
| 조기조림 | 중약불 | 15~20분 | 국물이 걸쭉 |
| 오징어조림 | 중불 | 8~12분 | 길면 급격히 질겨진다 |
| 멸치볶음·멸치조림 | 약불 | 5~8분 | 식으면 굳으므로 촉촉할 때 끝 |
| 무조림 | 중불 | 20~30분 | 반투명해지고 속까지 색이 듦 |
| 감자조림 | 중불 | 18~25분 | 겉이 살짝 부서지기 직전 |
| 연근·우엉조림 | 약불 | 25~35분 | 아삭함이 남는 정도 |
| 두부조림 | 약불 | 10~15분 | 국물이 자작 |

**기본 양념 비율** (재료 500g 기준, 물 포함)

| 계열 | 배합 | 특징 |
|---|---|---|
| 간장 조림 | 간장 60ml : 설탕 25g : 청주 15ml : 물 200ml | 단짠의 기본. 설탕:간장 약 1:2 |
| 고추장 조림 | 고추장 45g : 간장 30ml : 설탕 25g : 고춧가루 8g : 물 300ml | 고추장은 조금씩 더한다. 오래 끓이면 쓰다 |
| 생선 조림 | 간장 45ml : 고춧가루 15g : 다진마늘 15g : 청주 30ml : 물 250ml | 무를 밑에 깐다 |

## 변수

| 변수 | 방향 | 결과 |
|---|---|---|
| 국물 양 | 적을수록 | 빨리 졸지만 탈 위험이 커진다 |
| 불 세기 | 시머 유지 | 세게 끓이면 겉만 풀어지고 국물이 탁하다 |
| 뚜껑 | 초반 덮고 후반 연다 | 계속 덮으면 졸지 않고, 계속 열면 마른다 |
| 재료 크기 | 클수록 | 시간이 늘고 형태 유지에 유리하다 |
| 당의 종류 | 물엿·꿀은 빨리 탄다 | 마지막 3~5분에 넣는다 |
| 압력 | 121°C | 콜라겐 전환 시간이 1/3로 준다 |
| 뒤집기 | 5~10분에 한 번 | 잦으면 부서진다 |

## 흔한 실수

| 증상 | 원인 | 대처 |
|---|---|---|
| 마지막에 갑자기 탔다 | 국물이 줄며 온도가 올랐다 | 마지막 5분은 옆에 붙어 있는다 |
| 고기가 뻣뻣하고 퍽퍽하다 | 60~68°C 구간에서 멈춤 | 더 오래 시머. 시간이 부족한 것이지 과했던 게 아니다 |
| 생선이 다 부서졌다 | 자주 뒤집음, 찬 국물에 투입 | 국물을 먼저 끓이고 뒤집기는 한 번 |
| 겉만 짜고 속은 싱겁다 | 국물이 너무 짜고 시간이 짧음 | 국물을 묽게 하고 시간을 늘린다 |
| 국물이 안 졸아든다 | 뚜껑을 계속 덮음 | 후반에는 뚜껑을 연다 |
| 고추장 양념이 쓰다 | 고추장을 초반에 넣고 오래 끓임 | 중반 이후에 넣는다 |
| 감자가 죽처럼 풀어졌다 | 크기가 작고 오래 끓임 | 큼직하게 썰고 중반에 넣는다 |

**윤기는 마지막 30초에 만든다.** 불을 살짝 올려 국물을 끼얹으며 졸이면 당이 표면에 얇게 코팅된다. 물엿을 쓸 경우 이 시점에만 넣는다 — 먼저 넣으면 환원당이 먼저 타서 쓴맛이 난다.

## 적용 요리

| 요리 | 전략 | 핵심 |
|---|---|---|
| 갈비찜 | 데침 → 시머 → 졸임 | 콜라겐 전환에 필요한 시간을 준다 |
| 장조림 | 삶기 → 결대로 찢기 → 조림 | 고기를 먼저 무르게 하고 나중에 간을 한다 |
| 감자조림 | 중불 단일 구간 | 큼직하게 썰어 형태를 지킨다 |
| 두부조림 | 지진 뒤 조림 | 표면을 지지면 부서지지 않는다 |
| 닭볶음탕 | 볶기 → 조림 | 볶아서 색을 낸 뒤 국물을 붓는다 |
| 마늘종장아찌 | 절임 후 조림 국물 | 조림보다 절임에 가깝다 |
| 멸치볶음 | 짧은 조림 | 식으면 굳으니 촉촉할 때 끝낸다 |
