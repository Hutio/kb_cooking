# 삶기 (Boiling)

> 물을 열전달 매질로 쓰는 기법. 물이 있는 한 온도는 100°C를 넘지 못하므로 **온도가 아니라 시간과 물의 상태로 결과를 조절**한다. 실전에서 중요한 구분은 끓이느냐가 아니라 몇 도에서 익히느냐다.

## 원리

**물 상태별 온도와 눈으로 보는 신호는 [[끓이기]]가 정본이다.** 삶기에서는 세 구간이면 충분하다 — 수란·흰살생선·닭가슴살은 표면만 떨리는 포칭(대표값 75~80°C), 육수·콩은 바닥에서 기포가 올라오는 시머, 면·채소 데치기는 전면이 뒤집히는 센 끓음이다.

**열전달은 전도와 대류로 일어난다.** 물의 열전도와 대류는 공기보다 훨씬 효율이 좋아서, 100°C 물은 100°C 오븐보다 압도적으로 빨리 익힌다. 같은 이유로 **끓는 물에 손을 넣으면 100°C 오븐에 손을 넣는 것보다 훨씬 위험하다.**

**끓는 물과 시머는 온도가 거의 같다.** 97°C와 100°C의 차이는 조리 속도에 거의 영향이 없다. 차이는 **물리적 요동**이다. 세차게 끓으면 생선살이 부서지고 육수가 탁해지며, 단백질 응집물이 잘게 부서져 국물에 퍼진다. 맑은 국물을 원하면 온도가 아니라 기포를 줄여야 한다.

**소금은 끓는점 때문에 넣는 것이 아니다.** 물 1L에 소금 10g을 넣어도 끓는점은 약 0.17°C 오를 뿐이다. 조리 속도에 아무 영향이 없다. **소금을 넣는 이유는 간, 그리고 채소의 색과 조직 유지다.**

## 기본 방법

**찬물에서 시작할 것인가, 끓는 물에 넣을 것인가**가 첫 갈림길이다.

| 시작 | 대상 | 이유 |
|---|---|---|
| 찬물 | 사골, 수육, 마른 콩, 감자 통째 | 속과 겉이 함께 온도를 올려 균일하게 익는다. 단백질·불순물이 서서히 나와 걷어내기 쉽다 |
| 끓는 물 | 면, 잎채소, 새우, 계란 | 표면이 빨리 응고·고정돼 형태와 색이 유지된다. 물에 녹아 나가는 시간이 짧다 |

1. **물을 넉넉히.** 재료 무게의 최소 10배. 적으면 재료를 넣는 순간 온도가 떨어지고 회복이 느리다.
2. **완전히 끓인 뒤 소금을 넣는다.** 면은 물 1L당 소금 7~10g이 기준이다.
3. **넣고 다시 끓어오르면 목표 상태로 불을 줄인다.**
4. **거품을 걷어낸다.** 육류·콩에서 나오는 회색 거품은 응고한 단백질과 잡질이다.
5. **건진 뒤 처리를 정한다.** 면은 용도에 따라, 채소는 얼음물, 육류는 그대로.

**"고기에서 나오는 붉은 물은 피가 아니다."** 도축 과정에서 혈액은 대부분 제거된다. 붉은 것은 근육 색소인 미오글로빈이 녹아 나온 용액이다. 그래도 찬물에서 시작해 거품을 걷어내면 잡내와 탁함이 줄어든다.

**재료별 기준**

| 재료 | 물 상태 | 시간 | 판단 기준 |
|---|---|---|---|
| 시금치·잎채소 | 끓는 물 | 30~60초 | 색이 선명해지는 순간 |
| 브로콜리 | 끓는 물 | 2~3분 | 줄기에 꼬치가 살짝 들어감 |
| 감자(통, 중간) | 찬물 시작 | 20~25분 | 칼이 저항 없이 들어감 |
| 계란(냉장, 끓는 물 투입) | 끓는 물 | 반숙 6~7분 / 반숙 노른자 굳기 시작 9분 / 완숙 11~12분 | 시간으로 관리 |
| 스파게티 | 끓는 물 | 포장 표시 -1~2분 | 중심에 흰 심이 실낱만큼 |
| 새우 | 끓는 물 | 2~3분 | 몸이 C자로 굽고 불투명 |
| 오징어 | 끓는 물 | 30초~1분 | 넘기면 급격히 질겨진다 |
| 문어 | 약한 시머 | 40~60분 | 두꺼운 부분에 꼬치가 들어감 |
| 닭가슴살 | 포칭 75~80°C | 15~20분 | 심부 74°C |
| 수육(삼겹·목살) | 찬물 시작 후 시머 | 50~70분 | 꼬치가 저항 없이 통과 |
| 사태·양지 | 찬물 시작 후 약한 시머 | 1.5~2.5시간 | 결이 손으로 갈라짐 |
| 사골 | 찬물 시작 후 시머 | 6시간 이상, 여러 번 | 국물이 뽀얗게 유화됨 |

**계란의 응고 온도** — 흰자는 62~65°C에서 굳기 시작하고, 노른자는 65~70°C에서 되직해진다. 완숙 계란 노른자 겉면의 초록 테두리는 황화철이며 **과가열의 신호**다. 무해하지만 시간을 1~2분 줄이면 사라진다.

## 변수

| 변수 | 영향 | 비고 |
|---|---|---|
| 물의 양 | 온도 회복 속도 | 재료 무게의 10배 이상 |
| 기포의 세기 | 형태 유지, 국물 맑기 | 온도 차이는 거의 없다 |
| 소금 | 간, 채소의 색·조직 | 끓는점 상승은 무시할 수준 |
| 뚜껑 | 온도 유지 | 녹색 채소는 열고 삶아야 색이 산다 |
| 시작 온도 | 균일함 vs 형태 유지 | 위 표 참조 |
| 고도 | 100m마다 끓는점 약 0.3°C 하락 | 고지대는 시간이 길어진다 |
| 물의 경도 | 콩의 연화 속도 | 칼슘이 많으면 콩이 잘 안 무른다 |

**파스타 삶는 물에 기름을 넣는 것은 효과가 없다.** 기름은 물 위에 떠 있다가 면을 건질 때 표면에만 묻는다. 면이 붙는 것을 막는 것은 충분한 물과 초반 1분의 젓기이고, 기름막은 오히려 소스가 면에 붙는 것을 방해한다.

## 흔한 실수

| 증상 | 원인 | 대처 |
|---|---|---|
| 감자 겉은 무르고 속은 딱딱 | 끓는 물에 통째로 투입 | 찬물에서 시작한다 |
| 국물이 뿌옇고 잡내가 난다 | 센 불로 끓임 | 시머로 낮추고 거품을 걷는다 |
| 면이 서로 붙는다 | 물이 적고 초반에 안 저음 | 물을 늘리고 넣은 직후 30초 젓는다 |
| 계란 껍데기가 안 벗겨진다 | 아주 신선한 계란 | 1주 지난 것을 쓰고, 삶은 뒤 얼음물에 급랭 |
| 오징어·새우가 질기다 | 시간 초과 | 1~3분을 넘기지 않는다 |
| 채소 색이 누렇다 | 뚜껑을 덮고 오래 삶음 | 뚜껑을 열고 짧게, 이후 얼음물 |
| 콩이 몇 시간을 삶아도 안 무른다 | 오래된 콩, 또는 산·소금을 일찍 투입 | 물에 불리고, 산성 재료는 나중에 |

**삶은 물을 그냥 버리지 않는다.** 면수는 전분이 녹아 있어 파스타 소스의 유화와 농도 조절에 쓰이고, 채소 삶은 물은 국물 베이스가 된다. 다만 **시금치처럼 옥살산이 많은 채소의 데친 물은 버린다.**

## 적용 요리

| 요리 | 물 상태 | 핵심 |
|---|---|---|
| 파스타 면 삶기 | 강한 보일, 소금 1% | 표시 시간보다 1~2분 일찍 건져 소스에서 마무리 |
| 수육 | 찬물 시작 후 시머 | 향신 채소를 함께. 건진 뒤 국물에 두면 촉촉하다 |
| 삼계탕 | 약한 시머 | 세게 끓이면 살이 흩어진다 |
| 미역국 | 시머 | 미역을 참기름에 볶은 뒤 물을 붓는다 |
| 수란 | 포칭 75~80°C | 식초를 넣으면 흰자가 빨리 응고한다 |
| 콩국수용 대두 | 찬물 불림 후 시머 | 껍질을 비벼 벗기면 고소함이 는다 |
| 사골국 | 긴 시머 | 첫 물은 버리고 다시 시작한다 |
