# 무침 (Seasoning / Mixing)

> 익히거나 손질한 재료에 양념을 입혀 버무리는 무가열 마무리 기법. 열이 개입하지 않으므로 결과를 좌우하는 변수는 딱 둘이다 — **재료의 물기**와 **양념을 넣는 순서**.

## 원리

무침에서 양념은 재료 속으로 들어가지 않는다. **표면에 붙어 있을 뿐이다.** 그래서 표면의 상태가 곧 맛이 된다.

| 요인 | 무슨 일이 일어나는가 | 결과 |
|---|---|---|
| 남은 물기 | 양념을 희석하고 표면에서 밀어낸다 | 싱겁고 물이 고인다 |
| 소금·간장 | 삼투로 세포에서 물을 계속 끌어낸다 | 시간이 지날수록 물이 생기고 싱거워진다 |
| 참기름·들기름 | 표면에 소수성 막을 만든다 | 향이 살고 수분 이동이 늦춰진다 |
| 식초 | 세포벽 펙틴에 작용, 색소를 안정화 | 아삭함 유지, 붉은 색이 선명해진다 |
| 물리적 힘 | 세포가 터진다 | 세게 주무르면 물러지고 물이 나온다 |

**참기름을 먼저 넣으면 간이 안 배는 것이 사실이다.** 기름이 표면을 코팅하면 뒤에 넣는 소금·간장이 재료에 닿지 못하고 겉돈다. **간 → 향신 → 기름 → 깨** 순서가 원칙이다.

**생채와 숙채는 다른 시계로 움직인다.**

| 구분 | 재료 상태 | 물이 나오는 속도 | 무치는 시점 |
|---|---|---|---|
| 생채 | 생것 (오이·무·배추) | 빠르다. 15~30분이면 흥건 | 먹기 직전 |
| 숙채 | 데치거나 삶은 것 (시금치·고사리) | 느리다 | 30분~몇 시간 전 가능 |
| 절임 후 무침 | 소금에 절여 물을 뺀 것 | 이미 뺐으므로 느리다 | 미리 가능 |

## 기본 방법

1. **재료를 준비한다.** 잎채소는 데쳐 얼음물에 급랭, 생채소는 씻어 물기를 턴다.
2. **물기를 짠다.** 데친 나물은 두 손으로 뭉쳐 꽉 짠다. **비틀지 말고 눌러 짠다** — 비틀면 조직이 뭉개진다.
3. **간을 먼저 넣는다.** 소금 또는 국간장.
4. **향신 재료를 넣는다.** 다진 마늘, 대파, 고춧가루.
5. **기름을 넣는다.** 참기름 또는 들기름.
6. **깨를 뿌리고 가볍게 버무린다.** 손끝으로 헤치듯 섞는다.

**양념 기준** (데친 나물 200g, 생것 약 400g 기준)

| 양념 | 양 | 역할 | 대체 |
|---|---|---|---|
| 국간장 | 8~10ml | 간 + 감칠맛 | 소금 2~3g |
| 소금 | 2~3g | 간 | — |
| 다진 마늘 | 5~8g | 향 | 생략 가능 |
| 참기름 | 8~10ml | 향, 표면 코팅 | 들기름(고사리·취나물에) |
| 통깨 | 3~5g | 향, 식감 | 볶아 빻아 쓰면 향이 더 난다 |
| 고춧가루 | 5~8g | 매운맛, 색 | 무생채·콩나물무침 |
| 식초 | 10~15ml | 신맛, 아삭함 | 생채에만 |
| 설탕 | 5~8g | 신맛 완충 | 생채에만 |

**생채 양념은 식초와 설탕이 함께 간다.** 식초만 넣으면 날카롭고, 설탕이 신맛의 각을 깎아 준다. 대략 **식초 : 설탕 = 2 : 1**이 출발점이다.

## 변수

| 변수 | 방향 | 결과 |
|---|---|---|
| 물기 | 적을수록 | 간이 진하고 오래 간다 |
| 무치는 시점 | 생채는 직전, 숙채는 미리 | 시점을 바꾸면 다른 음식이 된다 |
| 손의 힘 | 약할수록 | 형태와 식감이 산다 |
| 소금 vs 간장 | 간장은 색과 감칠맛을 더한다 | 흰 나물은 소금으로 색을 살린다 |
| 참기름 vs 들기름 | 참기름은 밝고, 들기름은 묵직하다 | 고사리·취나물은 들기름 |
| 기름 투입 시점 | 마지막 | 먼저 넣으면 간이 겉돈다 |
| 보관 온도 | 냉장 0~4°C | 나물 무침은 2~3일이 한계 |

**참기름과 들기름은 발연점이 160~180°C로 낮은 향 기름이다.** 무침에서는 가열이 없으니 문제가 없지만, 같은 기름을 볶음에 쓰면 향이 날아가고 이취가 난다. **향 기름은 불을 끈 뒤에 쓰는 것**이 원칙이다.

## 흔한 실수

| 증상 | 원인 | 대처 |
|---|---|---|
| 접시 바닥에 물이 고인다 | 물기를 덜 짰거나 소금을 일찍 넣음 | 꽉 짜고, 생채는 먹기 직전에 무친다 |
| 간이 겉돌고 싱겁다 | 참기름을 먼저 넣음 | 간 → 향신 → 기름 순서 |
| 나물이 뭉개져 죽 같다 | 데치기 과다 또는 비틀어 짬 | 30~60초 데치고 눌러 짠다 |
| 다음 날 먹으니 싱겁다 | 삼투로 나온 물이 양념을 희석 | 물을 따라 버리고 소금을 조금 보탠다 |
| 색이 칙칙하다 | 간장 과다, 또는 데치기 과다 | 흰 나물은 소금, 데치기는 짧게 |
| 고춧가루가 겉돌고 뻣뻣하다 | 마른 채로 넣음 | 물이나 식초에 2~3분 불려 넣는다 |
| 마늘 냄새가 거칠다 | 다진 마늘 과다 | 나물 200g에 5~8g을 넘기지 않는다 |

**"오래 재우면 속까지 밴다"는 무침에서는 특히 통하지 않는다.** 소금 외 대부분의 양념 성분은 표면 수 mm를 넘지 못한다. 오래 두어 달라지는 것은 간이 아니라 **물이 빠져 부피가 줄고 식감이 무너지는 쪽**이다.

**상함의 신호** — 표면에 실 같은 점액이 생기거나, 시큼한 냄새가 나거나, 국물이 뿌옇게 흐려지면 버린다. 참기름이 든 무침은 산패 냄새(눅눅한 크레용 냄새)도 폐기 기준이다.

## 적용 요리

| 요리 | 재료 상태 | 양념 계열 | 무치는 시점 |
|---|---|---|---|
| 시금치나물 | 30~60초 데침 | 국간장 + 참기름 | 미리 가능 |
| 콩나물무침 | 뚜껑 덮고 3~5분 데침 | 소금 + 참기름(+고춧가루) | 미리 가능 |
| 숙주나물 | 20~30초 데침 | 소금 + 참기름 | 미리 가능 |
| 고사리나물 | 불려 삶고 볶음 | 국간장 + 들기름 | 미리 가능 |
| 도라지무침 | 소금에 주물러 쓴맛 제거 | 고추장 + 식초 + 설탕 | 30분 전 |
| 무생채 | 생것 채썰기 | 고춧가루 + 식초 + 설탕 | 먹기 직전 |
| 오이무침 | 소금 절임 후 물기 짜기 | 고춧가루 + 식초 + 설탕 | 30분 전 |
| 파래무침 | 씻어 물기 짜기 | 초고추장 | 먹기 직전 |
| 가지나물 | 찌기 후 찢기 | 국간장 + 참기름 | 미리 가능 |
