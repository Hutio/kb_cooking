# 맛 (개요)

> 우리가 '맛'이라 부르는 것의 대부분은 혀가 하는 일이 아니다. 혀는 다섯에서 여섯 가지를 구분하고, 나머지는 코와 삼차신경과 입 안의 촉각이 만든다. 요리에서 맛을 다룬다는 것은 이 네 가지를 각각 다룬다는 뜻이다.

**세 가지만 기억하면 대부분이 설명된다**

1. **맛 성분은 열에 강하고 향 성분은 약하다.** 감칠맛도 짠맛도 끓여서 사라지지 않지만, 향은 끓는 내내 새어 나간다. "향은 마지막에"라는 규칙 전체가 여기서 나온다.
2. **소금 없이는 다른 맛이 드러나지 않는다.** 특히 감칠맛은 나트륨이 있어야 수용체에 결합한다. 밍밍한 국물의 원인은 대개 재료가 아니라 간이다.
3. **감칠맛 재료는 겹칠 때 곱해진다.** 글루탐산과 핵산계 성분을 함께 쓰면 각각의 합보다 훨씬 커진다. 다시마와 멸치, 토마토와 고기, 파르미지아노와 닭고기가 모두 같은 원리다.

**조미의 순서 — 왜 넣는 시점이 정해져 있는가**

| 시점 | 넣는 것 | 이유 |
|---|---|---|
| 가장 먼저 | 소금(밑간·염지) | 나트륨만이 재료 속으로 확산된다 |
| 초반 | 지용성 향신료, 장류의 일부, 열에 강한 허브 | 기름에 풀리고 우러날 시간이 필요하다 |
| 중반 | 단맛, 감칠맛 급원 | 당은 표면에 머물고 감칠맛은 열에 강하다 |
| 후반 | 간 맞추기 | 졸면서 농도가 올라가므로 마지막에 판단한다 |
| 불을 끄고 | 식초, 참기름, 후추, 연질 허브, 깨 | 전부 휘발성이다 |

**간은 식혀서 본다.** 온도가 높으면 짠맛 지각이 둔해져 계속 소금을 더 넣게 된다. 한 숟갈 덜어 잠깐 식힌 뒤 판단하고, 차게 낼 음식은 그보다 더 짜게 잡는다.

**자주 반복되는 오해**

| 통설 | 사실 |
|---|---|
| 혀에 맛을 느끼는 구역이 나뉘어 있다 | 반증됐다. 모든 기본 맛이 혀 전체에서 감지된다 |
| 감기에 걸리면 미각이 사라진다 | 미각은 멀쩡하고 코가 막혀 향이 끊긴 것이다 |
| 매운맛은 맛이다 | 미각이 아니라 삼차신경의 통각이다 |
| MSG는 몸에 해롭다 | 근거가 없다. FDA는 GRAS로 분류한다 |
| 천일염이 정제염보다 건강하다 | 미네랄 차이는 영양학적으로 무의미하다. 차이는 입자와 용해 속도다 |
| pH가 낮을수록 더 시다 | 총 산도가 더 중요하다. 같은 pH라도 유기산이 더 시다 |
| 끓이면 신맛이 날아간다 | 식초(초산)만 그렇다. 레몬의 구연산은 남는다 |
| 매울 때 물을 마신다 | 캡사이신은 물에 녹지 않는다. 유제품·지방이 듣는다 |
