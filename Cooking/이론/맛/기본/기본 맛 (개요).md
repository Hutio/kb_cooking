# 기본 맛 (Basic Tastes)

인간이 감지하는 5가지 기본 맛입니다. 이 맛들의 균형이 요리의 완성도를 결정합니다.

## 5가지 기본 맛

### [[단맛]] (Sweet)
- **성분**: 당류 (설탕, 과당, 포도당)
- **수용체**: T1R2/T1R3
- **역할**: 에너지, 균형, 보존
- **재료**: 설탕, 꿀, 과일, 물엿

### [[짠맛]] (Salty)
- **성분**: 나트륨 (소금, 간장)
- **수용체**: 이온 채널
- **역할**: 풍미 증폭, 보존
- **재료**: 소금, 간장, 된장, 젓갈

### [[신맛]] (Sour)
- **성분**: 산 (초산, 구연산, 유산)
- **수용체**: 이온 채널
- **역할**: 균형, 느끼함 중화, 보존
- **재료**: 식초, 레몬, 김치, 요거트

### [[쓴맛]] (Bitter)
- **성분**: 알칼로이드
- **수용체**: T2R (25종 이상)
- **역할**: 독성 감지, 복합미
- **재료**: 커피, 녹차, 케일, 자몽

### [[감칠맛]] (Umami)
- **성분**: 글루탐산, 이노신산, 구아닐산
- **수용체**: T1R1/T1R3
- **역할**: 단백질 감지, 만족감
- **재료**: 간장, 된장, 멸치, 다시마

## 맛 간의 상호작용

### 상승 (Synergy)
- **감칠맛**: 글루탐산 + 이노신산 = 8배
- **단짠**: 서로 강조

### 억제 (Suppression)
- **단맛**: 쓴맛 약화
- **짠맛**: 쓴맛 약화
- **신맛**: 단맛 약화

### 대비 (Contrast)
- **소금 + 수박**: 단맛 강조
- **설탕 + 자몽**: 쓴맛 완화

## 맛의 과학

### 미각 수용체
- **위치**: 혀 전체 (특정 부위 아님)
- **재생**: 10-14일마다 교체
- **민감도**: 나이·건강 상태에 따라 변화

### 후각의 역할
- **풍미**: 미각 20% + 후각 80%
- **역후각**: 음식 먹을 때 코로 올라가는 향
- **감기**: 후각 상실로 맛 못 느낌

### 온도의 영향
- **단맛**: 따뜻할수록 강함
- **쓴맛**: 차가울수록 약함
- **감칠맛**: 60-70°C 최적

## 맛 균형 맞추기

### 짠맛 과다
- 설탕, 크림, 물 추가
- 감자 넣어 흡수

### 단맛 과다
- 소금, 식초, 레몬즙
- 쓴맛 재료 (커피, 다크 초콜릿)

### 신맛 과다
- 설탕, 버터
- 베이킹소다 (소량)

### 쓴맛 과다
- 설탕, 크림
- 소금

### 맛 없음
- 소금 (가장 먼저)
- 감칠맛 재료
