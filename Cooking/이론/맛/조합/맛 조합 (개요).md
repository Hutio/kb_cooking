# 맛의 조합 (Taste Combinations)

두 가지 이상의 기본 맛을 조합하여 만드는 복합적인 풍미입니다. 한국 음식 문화에서 특히 발달했습니다.

## 주요 조합

### [[단짠]] (Sweet + Salty)
- **조합**: 단맛 + 짠맛
- **원리**: 대비 효과로 서로 강조
- **비율**: 설탕 1 : 간장 1 (기본)
- **요리**: 불고기, 갈비찜, 떡볶이, 양념치킨
- **특징**: 중독성, 풍미 증폭

### [[매콤달콤]] (Spicy + Sweet)
- **조합**: 매운맛 + 단맛
- **원리**: 단맛이 매운맛 완화, 균형
- **비율**: 고추장 2 : 설탕 1
- **요리**: 떡볶이, 양념치킨, 깐풍기, 라조기
- **특징**: 엔도르핀 + 도파민 이중 보상

### 신맛 + 단맛 (Sweet & Sour)
- **조합**: 신맛 + 단맛
- **원리**: 상큼하고 밝은 맛
- **비율**: 식초 1 : 설탕 1.5
- **요리**: 탕수육, 레모네이드, 과일 샐러드
- **특징**: 청량감, 느끼함 중화

### 짠맛 + 감칠맛 (Salty + Umami)
- **조합**: 짠맛 + 감칠맛
- **원리**: 짠맛이 감칠맛 돋보이게
- **재료**: 간장 + 육수
- **요리**: [[국 (개요)]], 조림
- **특징**: 깊이, 만족감

## 삼중 조합

### 단맛 + 짠맛 + 매운맛
- **요리**: 떡볶이, 양념치킨
- **특징**: 가장 중독성 높음
- **균형**: 세 맛의 비율 조절

### 신맛 + 단맛 + 짠맛
- **요리**: 탕수육, 피클
- **특징**: 복합미, 입맛 돋움

## 조합 원리

### 대비 효과
- 반대 맛이 서로 강조
- 소금 + 수박 = 단맛 강조
- 설탕 + 자몽 = 쓴맛 완화

### 상승 효과
- 비슷한 맛끼리 증폭
- 간장 + 육수 = 감칠맛 극대화

### 균형 효과
- 강한 맛을 부드럽게
- 단맛이 매운맛 완화
- 신맛이 느끼함 중화

## 문화권별 선호

### 한국
- [[단짠]], [[매콤달콤]]
- 발효 감칠맛

### 중국
- 단맛 + 짠맛 + 신맛
- 오향 (五香)

### 태국
- 신맛 + 단맛 + 매운맛
- 허브 향

### 서양
- 단맛 + 쓴맛 (초콜릿)
- 짠맛 + 지방

## 조합 활용 팁

### 단짠 만들기
1. 간장 베이스
2. 설탕 1:1 비율
3. 물엿으로 끈적임
4. 마늘, 생강으로 향

### 매콤달콤 만들기
1. 고추장 베이스
2. 설탕·물엿으로 단맛
3. 고춧가루로 매운맛 조절
4. 식초 약간 (신맛 포인트)

### 새콤달콤 만들기
1. 설탕 베이스
2. 식초 2:3 비율
3. 케첩으로 색과 풍미
4. 전분물로 농도
