# 홈

> 레시피 · 재료 · 이론 · 도구를 잇는 볼트 전체 지도. 어디서 시작해도 되지만, 재료를 먼저 읽으면 레시피가 훨씬 잘 읽힌다.

## 시작하기

### 재료부터 — 가장 단단하게 정리된 층

레시피는 "무엇을 얼마나"를 알려주고, 재료 문서는 "왜 그렇게 되는가"를 알려준다. 모든 재료 문서는 같은 순서로 쓰여 있다: **고르기 → 손질과 형태 → 보관(단기/장기) → 맛과 성분 → 조리 활용**.

1. [[조미료 (개요)]] — 간이 어긋나는 이유는 대개 여기 있다. 국간장과 양조간장, 천일염과 정제염
2. [[식재료 (개요)]] — 육류·해산물·채소·곡물·유제품 전체 지도
3. [[향신료 (개요)]] — 향은 휘발한다. 언제 갈고 언제 넣느냐의 문제

### 원리로 넘어가기

4. [[조리기법 (개요)]] — 8대 기본 기법
5. [[맛 (개요)]] — 기본 6맛과 조합
6. [[감칠맛]] — 이 볼트에서 가장 실용적인 문서 하나를 꼽자면

### 요리 만들기

7. [[한식 (개요)]] — 나물 반찬 → 찌개 → 메인
8. [[양식 (개요)]] — 파스타 → 샐러드 → 스테이크
9. [[소스 (개요)]] — 한식 양념, 파스타 소스, 드레싱

### 지도

폴더를 가로지르는 색인이다. 카테고리 개요가 "무엇이 있나"를 보여 준다면, 지도는 **하나의 축으로 볼트 전체를 다시 세운다.**

| 지도 | 축 | 무엇을 찾을 때 |
|---|---|---|
| [[발효 (지도)]] | 미생물 · 염도 · 온도 | 김치·장·치즈·빵이 왜 같은 기술인지 |
| [[감칠맛 급원 (지도)]] | 글루탐산 · 이노신산 · 구아닐산 | 국물이 밍밍할 때 무엇을 더할지 |
| [[냉동 보관 (지도)]] | 얼음 결정이 조직에 하는 일 | 이걸 얼려도 되는지, 얼리면 뭐가 되는지 |
| [[제철 (지도)]] | 월 | 이달에 뭘 사고 뭘 저장할지 |

## 추천 레시피

처음이라면 이 일곱 개부터. 각 계열의 기본형이라 응용이 넓다.

- [[김치찌개]] — 한식 국물의 기본형. 김치를 볶는 이유를 알면 나머지 찌개가 풀린다
- [[불고기]] — 간장 양념의 표준. 양념 비율 감각이 생긴다
- [[배추김치]] — 발효를 직접 다뤄 보는 문서
- [[까르보나라]] — 계란 유화. 실패 원인이 명확해서 배우기 좋다
- [[마르게리타 피자]] — 반죽·수분·오븐 온도의 관계
- [[짜장면]] — 춘장을 볶아야 하는 이유
- [[초밥]] — 밥 온도와 배합초. 재료보다 손이 결과를 가른다
